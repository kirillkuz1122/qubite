# Knowledge native gateway — старый сервис / reference

LEGACY REFERENCE13.10.2026. Исходники сохранены, но не подключены к новому ядру Qubite 2.0. Новый модуль требует отдельного обсуждения владельца, сценариев связей с Docs/Projects/Inbox/Command, новых core API/UUID/permissions/budgets и React интерфейса. Старые credentials/endpoints/глобальные роли не новый authority. Карта и discovery задачи: docs/legacy-services/README.md от корня checkout.

## Что здесь есть

`server.py` — приватный stdio MCP-мост для ИИ-помощника к двум отдельным приложениям:

- **Memos:** чтение, создание и изменение заметок, чтение пространств и комментариев.
- **Vikunja:** чтение, создание и изменение задач и проектов.

Например, помощник мог сохранить мысль в Memos или создать задачу в Vikunja. Сам мост не хранит заметки и не является собственной базой знаний Qubite. Он использует allowlist инструментов native API; удаление, управление пользователями и выдача токенов не публикуются как инструменты. Credentials передаются отдельным приватным файлом и не должны попадать в Git.

Действующая установка Memos/Vikunja этой задачей не проверялась. Для нового продукта они не выбраны как основа: дальнейшее назначение Knowledge и связи с собственными Docs/Planner/Atlas определяются в **QUB-SVC-KNOWLEDGE-000** после вопросов владельцу.
