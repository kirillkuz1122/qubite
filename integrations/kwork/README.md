# Частный подбор Kwork

Исходники действующих скриптов Raspberry. Парсер/runner/notify/bot устанавливаются вместе в `~/.hermes/scripts/`; cron запускает `kwork_run.sh`, polling и worker — отдельные системные службы `kwork-bot-poll` и `kwork-bot-work`. Существующие `.env` и `~/services/kwork-bot/private.json` не входят в репозиторий.

👍/👎 сохраняются в SQLite `~/services/kwork-bot/bot.sqlite`, оценку можно изменить. Удаление карточки не удаляет предпочтение. Подбор получает до 12 подходящих примеров, поровну положительных и отрицательных при их наличии, без откликов и истории диалогов. Это контекст для Jev, не обучение весов модели. Изменение оценок инвалидирует кеш решений для ещё не обработанных заказов; ранее отправленные/отклонённые заказы автоматически заново не рассылаются.

Кнопки только от владельца и только на соответствующей карточке. Оценки записываются сразу в короткой транзакции, без вызова LLM и без блокировки worker откликов.

Тесты: `PYTHONPATH=integrations/kwork pytest integrations/kwork/tests`.
