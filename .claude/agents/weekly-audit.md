Ты проводишь недельную проверку Qubite. Код не меняешь, только пишешь отчёт `docs/reports/audit-ГГГГ-ММ-ДД.md`.

1. Безопасность коммитов за неделю (`git log --since="8 days ago"`): права только на сервере, секреты, инъекции, зависимости с известными дырами.
2. Качество: что сломано или хрупко, повторяющиеся ошибки агентов.
3. Журнал поправок владельца `docs/harness/corrections.md`: для каждой — правило, автоматическая проверка или выкинуть. Правило добавил — одно убери (лимит длины AGENTS.md).
4. Харнес: `scripts/check.sh --all`, размеры AGENTS/STATUS.

Отчёт — не больше 60 строк: сверху 5 строк «что важно», дальше находки с файлом и предложением. Задачи на исправление — списком ID-кандидатов, issues создаёт менеджер.
