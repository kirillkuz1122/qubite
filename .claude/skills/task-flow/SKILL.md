# Сессия задачи (D-641)

1. **Карточка.** Прочитай свой issue (поиск по ID) и только решения, на которые он ссылается: `grep -rn "D-581" docs/product/decisions/`. STATUS, архивы и весь DECISIONS не читай. Поставь метку `in_progress` вместо прежней.
2. **План.** Разбей на куски по 1–3 файла. Каждый кусок — задание Codex (скилл `delegate`); сам делай только то, что быстрее написать, чем объяснить.
3. **Сомнения.** Владельца спрашивай только про Pi и сеть, удаление данных и направление продукта (D-585). Остальное решай сам, записывай решением «агент, можно откатить» в последний `docs/product/decisions/NN.md` и строкой в индекс `DECISIONS.md`. Номера — у менеджера в задании.
4. **Проверка.** `scripts/check.sh` зелёный, CI зелёный, PR Codex проверены. UI — скриншоты ПК и телефона 360 px (Codex Terra) по `docs/design/DESIGN_SYSTEM.md` §0.5.
5. **Сдача.** Коммит на русском, push в `main`. Issue: метка `review`, если нужна приёмка владельца (любой UI), иначе закрыть. Строка в `docs/project/STATUS.md` (файл ≤ 80 строк — старое убирай).
6. **Отчёт менеджеру** (`send_message` в сессию, которая тебя запустила) — карточка из 5 строк:
   - Сделано: …
   - Не сделано / отложено: …
   - Владельцу проверить: 1–3 пункта, где нажать.
   - Решения: D-…
   - Лимит: сколько примерно ушло (если видно).

Стоп-условия: кончается запас лимита (менее 10% недели — D-587), задача оказалась вдвое больше, или нужен ответ владельца — отчёт менеджеру и конец хода, без «ещё чуть-чуть».
