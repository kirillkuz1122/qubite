# Делегирование (D-640)

Сам пишешь мало: ты ставишь задание, принимаешь результат и отвечаешь за него. Помощников ровно три вида, других нет (не запускай Opus/Sonnet-подагентов):

| Кто | Как вызвать | Для чего |
|---|---|---|
| **GPT 6.1 Sol** (Codex) | issue с меткой `codex` + `codex-model:sol` | обычный код по готовому заданию |
| **GPT 6.1 Terra** (Codex) | issue с меткой `codex` + `codex-model:terra` | проверки «руками»: браузер, скриншоты, потыкать интерфейс. Terra на Pi может ставить зависимости, запускать приложение и Playwright; Sol — только код (D-682) |
| **Haiku** | агент `scout` (Agent tool) | найти файлы, разобрать лог или вывод, выжимка до 15 строк |

Уровень рассуждения Codex — метка `codex-effort:medium|high|xhigh`. Обычно `high`; `xhigh` — сложное (протоколы, безопасность, тонкий баг). Точные имена моделей и умолчания — `docs/harness/CODEX.md`.

## Задание для Codex (тело issue)
Заголовок «ID — что сделать». В теле, до 40 строк:
1. **Цель** — одна фраза, зачем.
2. **Файлы** — какие трогать, какие нельзя.
3. **Прочитать** — только названные решения (`D-…`) и файлы.
4. **Готово, когда** — проверяемо: команда, тест, поведение.
5. **Нельзя** — `legacy/`, сырые цвета в UI, отключать тесты, секреты.
6. **Отчёт** — в PR: сделано / не сделано / нужно от человека / какие проверки прошли.

Связь с задачей — «Часть #N» в теле. Codex сам делает ветку `codex-issue-N` и PR, метка `codex:готово` или `codex:ошибка` (D-632).

## Ревью
- Код Codex ты проверяешь всегда (D-621): читаешь дифф PR, запускаешь `scripts/check.sh`, смотришь CI. Плохо — комментарий в PR, поправки в текст issue и снять `codex:готово` (Codex читает только текст issue).
- Ревью любого PR делает Codex-бот GitHub сам, при открытии PR (D-648): итог — комментарий «Codex Review Summary», 👍 если замечаний нет. После правок — комментарий `@codex review`. Очередь `codex-review` на Pi — только когда нужно ревью с браузером или запуском приложения.

## Пока ждёшь
Codex работает минуты. Не опрашивай в цикле: поставь будильник `send_later` (10–20 минут) или подпишись на PR (`subscribe_pr_activity`) и закончи ход.
