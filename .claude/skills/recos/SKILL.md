# /recos — пятничные предложения

Запуск в пятничной облачной сессии по подписке. Выполняй команды из корня репозитория.

1. Запусти `python3 scripts/pult_recos.py week`. Посмотри сессии (агент, модель, токены, цена), топ задач и расход по дням. Ищи дорогие повторения, ручную работу и места, где правила приходится объяснять заново. При ошибке чтения сводки сообщи о ней и не отправляй карточки.
2. Возьми за образец карточки из `docs/design/screens/AOS-4/figma/recos-pc.png` и подходящие приёмы из `docs/design/REFERENCES.md`. Для каждой идеи запиши наблюдение из сводки, конкретное изменение, усилие, ожидаемую экономию и затронутые файлы. Если экономия пока неизвестна, напиши об этом. Числа с макета служат примерами оформления.
3. Сделай восемь карточек по образцам с `joker: false`. Разложи идеи по ARMS: `apps` — приложения и инструменты, `routines` — повторяющиеся задачи, `memory` — контекст и правила, `skills` — навыки и их модели.
4. Сделай ещё две карточки с `arms: "jokers"` и `joker: true`. В каждой предложи идею намеренно мимо образцов и в `will_do` объясни, чем она отличается и зачем. Сохраняй доступность и правила `docs/design/DESIGN_SYSTEM.md` §0. Удачного джокера добавляют в `docs/design/REFERENCES.md` и фиксируют решением только по выбору владельца (D-1084, D-1095).
5. Используй только рабочие наблюдения и обезличенные числа. Не переноси из сводки личные данные, содержимое переписки, адреса или секреты. Не читай профиль владельца для генерации карточек (D-938).

Сохрани рабочий `FILE.json` вне отслеживаемых файлов репозитория. `week` — ISO-неделя сводки (`ГГГГ-WНН`), при отсутствии поля возьми ISO-неделю пятничного запуска. У каждой карточки свой короткий `ref`. Полный список `cards` содержит десять объектов такого вида:

```json
{
  "week": "2026-W47",
  "cards": [
    {
      "ref": "memory-1",
      "arms": "memory",
      "title": "Убрать повтор правила",
      "noticed": "Одно правило читают в двух файлах",
      "will_do": "Оставлю правило в AGENTS.md и поставлю ссылку в CLAUDE.md",
      "effort": "S",
      "saving": "Экономию пока не измерили",
      "files": ["AGENTS.md", "CLAUDE.md"],
      "joker": false
    }
  ]
}
```

Длина `title` — до 80 символов, `noticed` и `will_do` — до 300 каждый. `effort` — `S`, `M` или `L`. Экономия — текстом, файлы — путями относительно корня репозитория.

6. Проверь файл командой `python3 scripts/pult_recos.py send FILE.json --dry-run`. Если проверка прошла, запусти `python3 scripts/pult_recos.py send FILE.json`. Скрипт читает токен сборщика из окружения или `~/.config/qubite/pult.env`. Токен не выводи и не записывай в JSON. Карточки появятся во вкладке Recos Пульта.
7. Запусти `python3 scripts/pult_recos.py calibrate` и приложи таблицу к пятничному отчёту рядом с Recos. Таблица остаётся черновиком для `/calibrate`. Правила и журнал меняются только по «да» владельца (D-1082).
