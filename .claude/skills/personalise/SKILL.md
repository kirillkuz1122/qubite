# /personalise — навык под владельца

1. Возьми навык (`SKILL.md`). Чужой — сначала лицензия: только из `deny.toml`-совместимых, копирайт сохранить, строка в `THIRD_PARTY_LICENSES` (D-840).
2. Узнай владельца из **того, что уже записано**: в общем харнессе — `USER.md`, `SOUL.md`; в проекте — AGENTS.md, `corrections.md`, решения. Не хватает — не больше 3 коротких вопросов, голосом владелец отвечает кашей, понимай по смыслу.
3. Перепиши в навыке: язык и тон («ты», по-русски, без воды, «почему»), примеры из его стека, что он не любит. Убери всё лишнее — навык после правки должен быть **короче**.
4. В навык пиши только общее и рабочее (приёмы, формат, правила). **Личные данные владельца в навык не копируй**: навык лежит в публичном репозитории, профиль — только в приватном харнессе (D-938). Нужен факт о владельце — ссылка «см. `USER.md`», а не копия.
5. Поставь в шапку `model:` — самую дешёвую, на которой навык справляется (haiku — выжимки и записи; sonnet — большинство; opus — только сложное).
6. Покажи дифф и жди «да» (как в `/calibrate`); без «да» файл не меняется.
