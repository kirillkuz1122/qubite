# Безопасность Qubite

## Сообщить об уязвимости

Не открывайте публичный issue. Напишите владельцу проекта лично (контакт в профиле GitHub `kirillkuz1122`). Опишите проблему, шаги воспроизведения и возможный ущерб.

## Принципы нового Qubite

- **По умолчанию запрещено.** Новый пользователь не получает модулей и AI; доступ выдаёт владелец ([AUTH_AND_PERMISSIONS](docs/architecture/AUTH_AND_PERMISSIONS.md)).
- **Проверки на сервере** для HTTP, WebSocket, фоновых задач, агентов, плагинов и MCP. Скрытие в интерфейсе — не защита.
- **Деньги под замком.** Платные AI-вызовы только через AI-шлюз с атомарным резервированием бюджета ([AI_COST_GUARD](docs/architecture/AI_COST_GUARD.md)).
- **Секреты** не попадают в git, логи, скриншоты, ответы API и AI-контекст. В репозитории только `.env.example`.
- **Пароли** — Argon2id; токены сессий и приглашений хранятся хешами.
- **Приватное отдельно.** Дневник и личная память AI не попадают в общий поиск, команды, плагины и публичные ссылки.
- **Внешний текст — данные, а не инструкции** (защита от prompt injection).
- **Аудит:** изменения прав, бюджетов и настроек журналируются неизменяемо.
