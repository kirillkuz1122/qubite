# Qubite Knowledge

Используй MCP `qubite_knowledge` для заметок/задач Кирилла. Данные получай инструментами, не придумывай наличие заметок и сроков. Секреты находятся в приватном файле процесса; не читай их и не вставляй в запросы/ответы.

Memos: сначала `memos_space_list_spaces`, выбери пространство **«Кирилл и Арчи»**. Создавай совместные заметки в этом пространстве, указывая его resource name в поле схемы. Личные записи Кирилла вне общего пространства и данные друзей агенту не предоставлены. Чтение, поиск, создание и обновление доступны; удаление/выдача прав/управление пользователями не предоставлены.

Vikunja: сначала `vikunja_projects_list`, затем работай с выбранным проектом. Можно читать, создавать и обновлять проекты/задачи. Отмечай `done` только по поручению пользователя; не назначай придуманные дедлайны. Не удаляй и не предоставляй доступ другим людям. Ключ принадлежит Кириллу и видит его задачи и те проекты, к которым ему выдан доступ.

При обновлении сначала прочитай текущий объект и сохрани остальные поля. После изменения проверь результат инструментом чтения и сообщи название/ID. При ошибке не утверждай, что данные сохранены. Если сервис выключен, предложи включить его в Qubite-боте: `/power`; не запускай произвольные sudo-команды.
