# @qubite/ui — «Частицы» в коде

Токены, шрифты и компоненты выбранного направления «Частицы» ([D-154…D-167](../../docs/product/DECISIONS.md)). Живые макеты лежат в [docs/design/explorations/2026-10-17-chastitsy](../../docs/design/explorations/2026-10-17-chastitsy/), витрина — маршрут `/design` в `apps/web`.

## Подключение

```tsx
import { LookProvider } from '@qubite/ui';
import '@qubite/ui/styles.css'; // токены обеих тем, шрифты Fira Code и Tiny5, стили компонентов

<LookProvider>{app}</LookProvider>;
```

- **Тема.** Задаётся атрибутом `data-theme` на `<html>`: `dark` или `light`. Человек выбирает `dark`, `light` или `auto`; выбор хранится в браузере под ключом `qubite.look.v1`.
- **Без мигания.** Чтобы светлая тема не мигала тёмной, `apps/web/index.html` ставит тему до первой отрисовки.
- **Цвета.** В CSS — `var(--q-<имя>)`, на холстах — `PALETTES[тема]`. Имена одинаковые в обеих темах, значения совпадают с `tokens.css`. Тест проверяет и совпадение, и контраст текста.
- **Форма точки.** Переменная `--q-round`: 0 — квадрат, 1 — круг. Кнопки, строка Command и панели скругляются формулой `calc(var(--q-round) * половина высоты)`.

## Что есть

| Компонент | Что делает |
|---|---|
| `Button` | Заливка (`fill`) или рамка; под пальцем сжимается, тянется за пальцем и пружинит. Увёл палец далеко или Escape — нажатие отменено |
| `Segmented` | Варианты с перетекающей подложкой (`useFlow`), подложку можно тащить и бросать; `wrap` — в несколько рядов, подложка перетекает между рядами; `variant="chips"` — фильтры с числами |
| `Switch` | Ручка-точка вытягивается в сторону движения; её можно тянуть пальцем и бросать |
| `RingCheck` | Кольцо из 12 точек стягивается в одну зелёную |
| `Command` | Строка Command: под ней видно, куда ляжет запись. Разбор — `parseCommand`: дело, мысль, поиск, дневник или конспект |
| `DotText` | Надпись из точек (Tiny5); при смене `text` те же точки собираются в новое слово |
| `Companion` | Помощник из точек: Элик, Прото, Нейт, Фоти — дышат, моргают, смотрят на курсор и каретку |
| `DotIcon` | Значки из точек |
| `useLook` | Тема, форма и размер точки, ощущения (живость `tempo`, `lite`, `motion`, характеры `feel`); `set('theme', 'light', origin)` меняет тему волной точек от `origin` |
| `FEELS`, `feelOf` | Характеры живых элементов: «Собранный», «Живой», «Пружинистый» для кнопки, подложки, переключателя и ползунка |
| `Dock` | Телефон: нижняя «капля» разделов; подсветку можно тащить и смахивать; по кнопке Command строка вытекает влево, разделы сжимаются в точку текущего |
| `SideNav` | ПК: разделы, подсветка едет к пункту и тянется по пути |
| `PlusMenu` | «+» раскрывается в меню прямо из кнопки, плюс поворачивается в крестик |
| `CommandSuggest` | Карточка над строкой Command: что это и куда ляжет, ниже — найденное (`hits`), выбранный пункт (`active`), выбор пальцем (`onPick`); список — `listbox` для `aria-activedescendant` строки |
| `matchScore`, `normalize`, `fixLayout` | Поиск Command на устройстве: по началам слов, «ё» = «е», забытая раскладка («yfcn» → «нас») |
| `ExpandPage` | Строка раскрывается в страницу и сворачивается обратно в ту же строку |
| `Crew` | Четыре помощника в одном холсте (шапка раздела): нужный выпрыгивает снизу |
| `Range`, `DotGrid` | Ползунок: точка догоняет значение пружиной и тянется резинкой за край (поверх настоящего `input type=range`); фоновая сетка точек той же формы |
| `EdgeScroll` | Своя прокрутка: точки заголовков (`h2`) у правого края и «ты здесь»; зажал — линии и названия, ведёшь — страница едет к заголовку. Пока стоит, системная полоса скрыта |
| `useLeaving` | Список без рывков: пропавшее из списка доигрывает уход на своём месте, потом удаляется (с `useFlip`) |
| `Presence` | Блок появляется и уходит пружиной, удаляется только после ухода; `onLayout` — соседям пора подтянуться (`useFlip`) |
| `useSlide`, `useFlip`, `usePress`, `flyDot` | Выделение строки, которое перетекает; соседи подтягиваются; нажатие пружинит; точка долетает до цели |
| `useMedia`, `WIDE`, `typewriter` | ПК или телефон (от 900 px); подсказка, которая печатает сама себя |

## Ощущения

Хранятся вместе с видом (`qubite.look.v1`) и сразу попадают в общий цикл:
- **Живость** 50…150 % — `loop().tempo`;
- **Облегчённый режим** — `loop().lite` и `data-lite` на `<html>`: холсты считают через кадр, помощники не «дышат», фон без сетки;
- **Меньше движения** — как в системе / да / нет: `loop().reduce` и `data-motion="less"`;
- **Характеры** — `look.feel`: по одному на кнопку, подложку, переключатель, ползунок. Компоненты берут характер `feelOf(part)` в момент движения. По умолчанию — «Пружинистый» везде (выбор владельца, D-182); «Живой» — прежние массы DS-001/DS-007.

Настройки есть в разделе «Настройки» приложения и на витрине `/design` (там же три характера на каждый элемент).

## Правила

- Двигаем только `transform` и `opacity`. Пружины берём из `@qubite/motion`, массы — из `MASS`, характеры живых элементов — `feelOf`.
- Ничего не появляется и не исчезает рывком: уход — через `Presence`, соседи — через `useFlip` (D-183).
- Нажатие захватывает палец сразу (`usePress`, `Button`): элемент сжимается, а отпускание у края всё равно попадает в него.
- Растягивая полоску в 1 px, учитываем дробный масштаб экрана: браузер рисует её шириной в целое число физических пикселей (в `useFlow` — `midWidth()`). Широкие растягиваемые слои не годятся — браузер перерисовывает их каждый кадр.
- Размеры (`width`, `height`, `border-radius`) не пишем в каждом кадре — только когда они правда поменялись (так сделано в `useFlow`).
- Пружины — изменяемые объекты вне React: кадры пишут стили прямо из общего цикла, без перерисовки компонента. Поэтому в этом пакете выключены правила `react-hooks/immutability` и `react-hooks/refs`.
- Холсты сами перекрашиваются при смене темы (`recolorAll`). Надписи из точек появляются только после загрузки шрифта Tiny5.
