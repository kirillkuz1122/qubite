# @qubite/motion — одна физика

Любое движение в Qubite — пружина из одного «материала»: жёсткость 220, вязкость 20 (`MATERIAL`). Меняется только масса (`MASS`):
- точка и кнопка — 0,55;
- подсветка — 0,8;
- строка — 1;
- лист — 1,2;
- помощник — 2,1.

У живых элементов (кнопка, подложка, переключатель, ползунок) есть **характер** — `Feel`: масса и вязкость (упругость). Чем меньше вязкость, тем больше элемент качается. Таблица характеров — в `@qubite/ui` (`FEELS`), выбирает владелец.

Решения: [D-142](../../docs/product/DECISIONS.md), [D-167](../../docs/product/DECISIONS.md), [D-180, D-181](../../docs/product/DECISIONS.md).

```ts
import { loop, MASS } from '@qubite/motion';

const L = loop(); // один цикл на страницу, спит в скрытой вкладке
const s = L.spring(0, MASS.row);
s.onChange = L.render(() => {
  el.style.transform = `translateY(${s.x}px)`; // в кадре пишем только transform и opacity
});
L.to(s, 120); // к цели
L.kick(s, 300); // толчок (прыжок, отскок)
```

- `L.to(s, goal, feel)` — к цели и заодно надеть характер `{ mass, damping }`.
- `L.hold(s, x, v)` — пружину держит палец: положение задаёт жест, скорость `v` останется для броска после `to`.
- Если включено «меньше движения» (в системе или `L.reduce = true` из настроек), `to` сразу ставит пружину в цель, а `kick` ничего не делает. `L.reduce = null` — как в системе.
- `L.tempo` — живость: множитель времени физики (0,5 — вдвое спокойнее, 1,5 — живее). `L.lite` — облегчённый режим для холстов с точками.
- Когда двигать нечего, цикл засыпает (и в скрытой вкладке тоже).
- `L.tick(fn)` вызывает `fn` каждый кадр (для холстов с точками) и возвращает функцию отписки.
## Жесты

```ts
import { drag, rubber, project } from '@qubite/motion';

const h = drag(el, {
  axis: 'x', // палец пошёл по вертикали — отдаём жест прокрутке
  onStart: () => (from = s.x),
  onMove: ({ dx }) => L.hold(s, rubber(from + dx, 0, 200)), // за краями — резинка
  onEnd: ({ vx }) => L.to(s, nearestStop(project(s.x, vx))), // бросок: куда докатится
  onTap: () => {}, // просто нажали, не сдвинув
  onCancel: () => L.to(s, from), // Escape или система забрала палец — вернуть на место
});
h.destroy();
```

- Палец «захватывается» (pointer capture): жест не теряется, если палец ушёл за край элемента.
- `filter(e)` — с какого касания можно начинать (например, только с выбранного пункта).
- `Tracker` — скорость пальца по последним 100 мс.

- Тесты: `pnpm test`. Время в тестах ручное, браузер не нужен (жесты — на ненастоящем элементе).
