# @qubite/motion — одна физика

Любое движение в Qubite — пружина из одного «материала»: жёсткость 220, вязкость 20 (`MATERIAL`). Меняется только масса (`MASS`):
- точка и кнопка — 0,55;
- подсветка — 0,8;
- строка — 1;
- лист — 1,2;
- помощник — 2,1.

Решения: [D-142](../../docs/product/DECISIONS.md), [D-167](../../docs/product/DECISIONS.md).

```ts
import { loop, MASS } from '@qubite/motion';

const L = loop(); // один цикл на страницу, спит в скрытой вкладке
const s = L.spring(0, MASS.row);
s.onChange = L.render(() => {
  el.style.transform = `translateY(${s.x}px)`; // в кадре пишем только transform и opacity
});
L.to(s, 120); // к цели
L.kick(s, 300); // толчок (прыжок, отскок)
```

- Если в системе включено «меньше движения», `to` сразу ставит пружину в цель, а `kick` ничего не делает.
- `L.tick(fn)` вызывает `fn` каждый кадр (для холстов с точками) и возвращает функцию отписки.
- Тесты: `pnpm test`. Время в тестах ручное, браузер не нужен.
