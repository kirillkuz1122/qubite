# Документы без сети

## Потерянные дописки (DOC-002d, Q-87)

`watchLostEdits(doc, origin, callback)` наблюдает за блоками Lexical 0.52:
корень `root` — `Y.XmlText`, его блоки — вложенные `Y.XmlText` с атрибутами
`__type: 'block'`, `kind`, `checked`, `indent`. Текст лежит прямо в блоке,
между служебными `Y.Map` текстовых узлов; атрибуты и форматирование не входят
в найденную дописку.

Подключить после восстановления локальной копии, **до правок и обмена**.
`origin` должен совпадать с меткой серверного `Y.applyUpdate` (у `DocStore`
это сам экземпляр хранилища) и отличаться от метки местных правок:

```ts
import { watchLostEdits } from '@qubite/sync-client';

const stop = watchLostEdits(handle.doc, store, (lost) => {
  // Передать экрану предложение «В удалённый блок дописали — вернуть?».
  // lost: { text: string; kind: string; after: string | null }[]
  offerLostText(lost);
});

// При отсоединении редактора:
stop();
```

Если пришло удаление блока, возвращаются только его местные вставки текущего
`doc.clientID`, отсутствовавшие в векторе после предыдущей транзакции с этим
`origin`. Если блок уже удалён здесь, возвращаются только текстовые элементы,
пришедшие сейчас в этот блок. Исходный текст блока, обычные удаления, смена
`kind` и повторное применение обновления не вызывают сигнал. `after` — текущий
текст ближайшего предыдущего живого блока; `null` означает начало документа,
а пустая строка — существующий пустой блок. Несколько потерь одной транзакции
передаются одним вызовом в порядке блоков.

Решил так, можно откатить: пока наблюдатель работает, его `gcFilter` сохраняет
контейнеры удалённых блоков и связи с их элементами. Остальной мусор, включая
старые строки, Yjs собирает обычным образом. Это необходимо для поздних вставок:
после удаления самого контейнера Yjs превратил бы их в GC ещё до уведомления.
Чтение происходит в `beforeObserverCalls`, уведомление — в `afterTransaction`,
до сборки мусора. Используются внутренние поля Yjs 13.6.33 (`_start`, `Item`,
`ContentType`, `ContentString`); обновлять эту версию нужно вместе с тестами.

`stop()` можно вызывать повторно; он отсоединяет обработчики. Последний
наблюдатель восстанавливает прежний `gcFilter`, если его не заменил другой код.
Сохранённые контейнеры могут оставаться в памяти до уничтожения `Y.Doc`;
`destroy` автоматически останавливает наблюдателей. Найденный текст нужно
сохранить на стороне экрана: отдельной постоянной очереди восстановления здесь
нет, и уже собранную до подключения историю наблюдатель восстановить не может.
Возврат текста делает экран через Lexical; `restoreLost` и изменений `DocStore`
в этом модуле нет. Протокол обмена остаётся прежним.

Тесты `src/docs-lost.test.ts` строят два `Y.Doc` вручную, без сети и редактора.
По условиям задания на Raspberry Pi проверки не запускались; их выполняет CI.
