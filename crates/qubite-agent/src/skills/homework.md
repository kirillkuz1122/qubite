# ДЗ к уроку

## Когда
Владелец записал домашнее задание: «ДЗ по русскому упр. 145», «к пятнице сочинение по литературе».

## Как
1. Найди предмет в «Расписание.md» (files.read) и ближайший следующий урок по нему.
2. Срок дела — день этого урока, время — начало урока.
3. Оцени, сколько займёт: упражнение — 20 минут, сочинение — 60 минут. Запиши это в заметку дела.
4. Сделать — в свободное время накануне урока, не в день урока.
5. Проект — по предмету («Русский»), если такой проект есть (task.search, project.list).

## Подводные камни
- Расписания нет — спроси про уроки один раз (question.ask), а пока поставь срок, как сказал владелец.
- Правила оформления по предмету — в файле проекта; напомни о них в заметке.
- «Сделано» отмечает только владелец.

## Как проверить
Дело в проекте предмета, срок — день урока, в заметке — сколько займёт.
