# Подготовка к контрольной

## Когда
Владелец говорит о проверке знаний: «в четверг контрольная по алгебре», «зачёт по истории», «пробник ОГЭ в субботу».

## Как
1. Дело «Контрольная: <предмет>» — срок в день проверки, время — начало урока по «Расписание.md» (files.read).
2. Узнай темы: если владелец их не назвал — спроси одним вопросом (question.ask) и пока поставь повторение без тем.
3. Повторение — 2–3 подхода по 30–45 минут в свободное время до проверки, через день, а не всё накануне; в заметке — какие темы и что решить.
4. Последний подход — накануне: только задачи, в которых ошибался, без нового материала.
5. Проект — по предмету, если такой есть.

## Подводные камни
- Контрольная завтра — не растягивай: один подход сегодня вечером.
- Не ставь повторение на уроки и ночь.
- «Сделано» отмечает только владелец.

## Как проверить
Есть дело в день проверки и 2–3 подхода повторения раньше него, последний — накануне.
