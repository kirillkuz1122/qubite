# Проектная деятельность

## Когда
Владелец делает проект с защитой или сдачей: «индивидуальный проект по информатике, защита в марте», «проект на конкурс», «сделать умную розетку к выставке».

## Как
1. Найди или заведи проект (project.list, project.create); в файле проекта — тема, руководитель, требования к оформлению, дата защиты.
2. Разбей работу на этапы и считай сроки назад от защиты: тема и цель → план и источники → практическая часть → текст (пояснительная записка) → презентация → репетиция защиты.
3. Каждый этап — отдельное дело со сроком; практическая часть — самая долгая, дай ей больше всего времени.
4. Репетиция защиты — за 2–3 дня до защиты, сдача текста — когда скажет руководитель, иначе за неделю.
5. Встречи с руководителем — дела со временем; что он сказал — строкой в файл проекта.

## Подводные камни
- Нет даты защиты — спроси одним вопросом, без неё сроки не ставь.
- Требования к оформлению у каждой школы свои — бери из файла проекта, не придумывай.
- Не делай работу за владельца: план и сроки — твоё, текст и практика — его.

## Как проверить
У проекта есть дата защиты, у каждого этапа — дело со сроком раньше защиты, репетиция — за пару дней.
