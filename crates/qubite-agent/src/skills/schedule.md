# Записать расписание

## Когда
Владелец рассказал про уроки, кружки, тренировки: «русский по вт и чт третьим уроком», «в среду бассейн с 17 до 18».

## Как
1. Прочитай «Расписание.md» (files.read). Файла нет — заведи его files.create с шапкой таблицы.
2. Одна строка — одно занятие: «| вт, чт | 10:05 | 10:50 | Русский | школа | да |».
3. Новое занятие — memory.add строкой таблицы; изменилось — memory.patch одной строки.
4. В «Память.md» — строка-оглавление «расписание — в Расписание.md», если её ещё нет.

## Подводные камни
- «Третьим уроком» — это не время: спроси, когда начинается третий урок, или посмотри в соседних строках.
- Конец раньше начала сервер не примет; через полночь — двумя строками.
- «Не беспокоить» по умолчанию «да»: на уроке агент молчит.

## Как проверить
Сервер принял таблицу (нет ошибки), в «Агент → Записи» расписание читается.
