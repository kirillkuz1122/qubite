# Настольный питомец Qubite

Проба для bspwm на X11. Для запуска нужны Python, PySide6, Qt Quick, bspwm и работающий X11-композитор. На компьютере, где разрабатывалась проба, эти пакеты уже установлены.

Из корня репозитория:

```sh
python experiments/desktop-companion/companion.py
```

- Клик левой кнопкой вызывает реакцию, перетаскивание двигает питомца, правая кнопка меняет окрас. Питомец следует глазами за курсором и засыпает при неподвижном курсоре.
- При полноэкранном окне на одном из активных рабочих столов питомец скрывается. После выхода из полного экрана он возвращается, если его не скрыли вручную.
- Параметры запуска `--theme light`, `--reduced-motion`, `--pass-through`. Цвета читаются из действующих токенов Qubite.
- Из другого терминала можно вызвать тот же файл с действием `pass` (переключить пропуск кликов), `hide` (показать или скрыть) или `stop` (закрыть). Действие передаётся через локальный сокет пользователя, отдельный для каждого X11-дисплея.

## Горячие клавиши

При необходимости добавь в свой `sxhkdrc` строки ниже и подставь путь до репозитория. В просмотренной копии конфига точных совпадений с этими сочетаниями не было. Если `sxhkd` сообщает о конфликте, используй другую связку.

```text
super + ctrl + shift + p
    /usr/bin/python /путь/к/qubite/experiments/desktop-companion/companion.py pass

super + ctrl + shift + h
    /usr/bin/python /путь/к/qubite/experiments/desktop-companion/companion.py hide
```

После сохранения своего конфига перечитать его можно командой `pkill -USR1 -x sxhkd`. Прототип сам не правит файлы пользователя. Вход в Qubite, модель, микрофон, захват экрана и автозапуск в эту пробу не входят.

Подробности, план и проверка в [документе для ревью](../../docs/architecture/DESKTOP_COMPANION.md).

## Проверка в отдельной X11-сессии

```sh
bash experiments/desktop-companion/smoke-x11.sh
QUBITE_SMOKE_SIZE=360x780 QUBITE_SMOKE_THEME=light \
    bash experiments/desktop-companion/smoke-x11.sh --reduced-motion
```

Для проверки используются Xvfb, xauth, picom, sxhkd, xdotool, xwininfo и ImageMagick. Скрипт поднимает свой bspwm, свой сокет и тестовое окно. `QUBITE_SMOKE_MEASURE=1` измеряет CPU и RSS процесса питомца, `QUBITE_SMOKE_SCREENSHOT=/tmp/companion.png` сохраняет кадр вымышленного рабочего стола. Проба использует программный рендер Qt Quick по умолчанию. Фоновый расход на реальном компьютере нужно замерить отдельно.
