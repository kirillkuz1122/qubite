# Qubite Writing — проверка и редактор текста

Открыть: `https://qubiteapp.online/writing` или Qubite → Мои сервисы → Редактор.
Нужно войти в Qubite. Владелец имеет доступ; друзьям его выдают в Администрирование → Пользователи → Редактор. Доступ независим от поиска и хранилища.

## Что умеет

- LanguageTool 6.6 проверяет русский и английский локально на сервере. По умолчанию русский, авто выбирает только между ru/en. Общие зависимости других языков из официального архива не удаляются, но проверка их не запускается.
- Четыре отдельные ИИ-команды: сложная проверка, улучшение с сохранением авторского стиля, смена выбранного/своего стиля, улучшение промпта.
- ИИ заменяет текст сразу; есть отмена. Если исходник изменился во время запроса, результат показывается отдельно. Отмена не перезаписывает более поздние пользовательские правки.
- Это собственная интеграция открытого LanguageTool, не лицензия на облачные Premium-функции. Набор локальных правил отличается от коммерческого сервиса. ИИ может ошибаться, включая ложные замечания и пропуск ошибок. Jev не используется как гарантия отсутствия ошибок и не запускается платно перед каждой правкой.
- Тексты и ответы не сохраняются в БД/историю. В SQLite остаются права, хеши ключей и технический учёт вызовов/расходов. ИИ по кнопке передаёт текст OpenRouter и выбранному провайдеру; локальная проверка остаётся на Raspberry.

## Бюджет и модель

Используется `mistralai/mistral-small-24b-instruct-2501`, только `deepinfra/fp8`, `allow_fallbacks=false`, потолок цен $0.05/миллион входных и $0.08/миллион выходных токенов. Платных автоматических повторов нет. Цены проверены в каталоге OpenRouter 05.10.2026; если endpoint/тариф изменится, нужен пересмотр настройки, а не обход ценового ограничения.

Отдельный ключ `WRITING_OPENROUTER_API_KEY` или файл `WRITING_KEY_FILE` с правами 600. Ключ поиска не используется. Общий дневной бюджет по умолчанию 5 ₽, меняется владельцем в редакторе. Дни считаются по UTC. Курс учёта задаётся `WRITING_RUB_PER_USD`, дата — `WRITING_RATE_DATE`; это фиксированная настройка, не автоматически обновляемый обменный курс. На этой установке начальная настройка 100 ₽/$ по выбору владельца, ровно $0.05/день. Изменение фактического курса может изменить рублёвую стоимость; актуализируйте настройку при необходимости.

У друзей отдельно: разрешение ИИ, число всех проверок/ИИ-вызовов в день и личный рублёвый лимит. Ноль запрещает соответствующие вызовы, пустое поле снимает личный лимит. Общий лимит действует всегда, включая владельца. До запроса резервируется консервативная оценка цены; затем учитывается `usage.cost`. Если запрос оборвался и цена неизвестна, резерв остаётся до конца UTC-дня, чтобы сбои не позволяли превысить бюджет. Учёт расходов не содержит текстов.

## Firefox и Zen

Нужно Firefox **142 или новее**, либо актуальный Zen на совместимой версии Firefox. Zen поддерживает дополнения Firefox: https://docs.zen-browser.app/user-manual/extensions. Пакет: кнопка «Скачать расширение Firefox / Zen» в редакторе. Это наше дополнение, а не модификация закрытого современного расширения LanguageTool.

Для теста:

Версия 0.1.2 исправляет ошибку «Недоступная команда» при проверке подключения. Для обновления скачай новый XPI поверх предыдущего файла, затем в `about:debugging` у Qubite Writing нажми «Перезагрузить». Если файл лежит по другому пути, удали временное дополнение и загрузи новый пакет; при необходимости вставь ранее созданный ключ ещё раз. Новый ключ специально для этого исправления не требуется.

1. В Firefox или Zen открой `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → выбери скачанный `.xpi` (или распакованный `manifest.json`). Такое дополнение исчезает после закрытия браузера.
2. В Qubite Writing раскрой «Подключить расширение / горячую клавишу», создай ключ «Zen» и скопируй его. Он начинается с `qbw_`, показывается один раз и наследует текущие права аккаунта. Не вставляй сюда ключ OpenRouter.
3. Открой настройки Qubite Writing через его кнопку на панели расширений. Адрес — `https://qubiteapp.online`, ключ — созданный `qbw_…`. Сохрани и проверь подключение.
4. Обнови страницы. В активном текстовом поле появится ✓/число замечаний. Нажми для правил/ИИ-команд/стиля/отмены. ИИ работает с выделенным фрагментом или всем полем. Правила проверяют всё поле.
5. Автоматическая локальная проверка выполняется после двух секунд паузы. Её можно выключить в настройках. «Не проверять этот сайт» исключает текущий домен и его поддомены; список редактируется в настройках.

Пароли, одноразовые коды и распознанные платёжные поля пропускаются. В сложных редакторах (внутренний документ, canvas, закрытый Shadow DOM) интеграция может не сработать: вставь текст в редактор Qubite. Форматированный contenteditable заменяется обычным текстом, поэтому используй ИИ там, где допустима замена форматирования. В первой версии замечания находятся в меню; полное подчёркивание в каждом нестандартном редакторе не обещается.

### Постоянная установка: подпись Mozilla

Обычный Firefox требует подпись собственного дополнения. Аккаунт на addons.mozilla.org нужен для этой подписи; пользователям подписанного пакета аккаунт не нужен.

1. Создай/войти в аккаунт разработчика на https://addons.mozilla.org/developers/.
2. «Submit a New Add-on» → распространять самостоятельно (**On your own / unlisted**). Это подпись для самостоятельного распространения, не публикация в общем каталоге.
3. Загрузи собранный XPI; укажи, что дополнение передаёт содержимое активного поля на заданный пользователем Qubite, а ИИ — по кнопке. Исходники находятся в `integrations/qubite-writing/firefox`, сторонних JS-библиотек/сборочной минификации нет. Mozilla может запросить проверку и пояснения.
4. Скачай подписанный `.xpi`; установи через about:addons → шестерёнка → «Установить дополнение из файла». Этот пакет можно дать друзьям. Каждый вводит свой Qubite Writing ключ.

Подпись не выполнена автоматически: для неё нужны твой аккаунт Mozilla и итоговое решение о распространении. Не отключайте проверку подписей Firefox. Для следующей версии измените manifest version, повторите подпись; AMO/signing API credentials не добавляйте в репозиторий.

## Linux — выделенный текст по горячей клавише

Скачай `linux.py` из редактора. Интерфейс использует Tk, а если Tk недоступен — установленный PySide6. Нужен `python3-tk`/`tk` либо `python-pyside6`; для чтения выделения нужны `wl-clipboard` (Wayland) или `xclip` (X11).

```bash
mkdir -p ~/.local/bin
cp ~/Загрузки/linux.py ~/.local/bin/qubite-writing
chmod +x ~/.local/bin/qubite-writing
python3 ~/.local/bin/qubite-writing --configure
```

Введи HTTPS-адрес Qubite и отдельный `qbw_` ключ. Он хранится в `~/.config/qubite-writing/config.json` с правами 600. Далее в настройках клавиатуры рабочего стола назначь команду `python3 /home/ТВОЙ_ПОЛЬЗОВАТЕЛЬ/.local/bin/qubite-writing` на свободную комбинацию, например Ctrl+Alt+W. Это выбор пользователя: разные рабочие столы используют разные настройки, занятые комбинации не перезаписываются.

Выдели текст, нажми комбинацию, проверь/перепиши. ИИ заменяет текст **в окне помощника**, с отменой. «Принять и скопировать» → вернись в исходную программу → Ctrl+V. Автоматический ввод в произвольное приложение не используется. Это работает шире браузера, но не создаёт фонового подчёркивания во всех программах.

## API и эксплуатация

Cookie API редактора: `/api/writing/me`, POST `/api/writing/check`, POST `/api/writing/rewrite`. Ключи создаются/отзываются через `/api/writing/keys`. Для расширения/CLI: те же операции под `/api/writing/v1/`, только `Authorization: Bearer qbw_…`; cookie-сессия там не является авторизацией. Ключи хранятся только как SHA-256. Отзыв ключа, блокировка пользователя или отзыв доступа действуют на следующий запрос.

`check`: `{"text":"Привет ребята","language":"ru"}` → формат LanguageTool `matches` с UTF-16 offsets. `rewrite`: `{"text":"...","mode":"check|improve|style|prompt","style":"деловой"}` → `text`, `notes`, `questions`, `model`, `cost_usd`. Не вставляйте ответ как HTML. Максимум 8000 UTF-16 единиц на запрос; чрезмерно длинный/оборванный ответ не подменяет оригинал сырым JSON.

LanguageTool слушает только loopback 9091, снаружи порт не нужен. Java heap максимум 384 МБ, один активный checker, Nice=10, ограничения systemd: 700 МБ RAM / 1 CPU при поддержке соответствующих cgroups. На Raspberry наблюдалось около 480–505 МБ RSS; проверяйте `ps`, поскольку система не всегда показывает `MemoryCurrent`. Первое использование языка после старта может занять 9–10 секунд; повторные короткие проверки быстрее. Пулы словарей ограничены двумя, кеш предложений выключен.

Свежая установка: `sudo bash deploy/install.sh` → выбрать редактор. Нужна платформа Qubite; сетевой режим остаётся общим (белый IP или Cloudflare). Дополнительный публичный порт/домен не создаётся. Инсталлятор скачивает официальный LanguageTool 6.6, проверяет SHA-256, устанавливает Java, создаёт `qubite-languagetool.service` и собирает неподписанный Firefox XPI. После изменения ключа/env перезапустите только qubite-platform.

Тесты: `node --test back/tests/writing.test.js back/tests/writing-addon.test.js back/tests/services.test.js back/tests/telegram-services.test.js`; `npx web-ext lint --source-dir integrations/qubite-writing/firefox`; `python3 -m unittest discover -s deploy/services/tests`.

Визуальные компоненты редактора импортируются из канонического `front/css/styles.css`, в соответствии с [design-system.md](design-system.md): Manrope/Jura, штатный логотип, розово-янтарный акцент, glass-panel/card-accent-top. Отдельного рекламного hero и собственной палитры нет.

На компьютере Кирилла помощник установлен как `~/.local/bin/qubite-writing`, настроен отдельным отзываемым ключом; в `~/.config/sxhkd/sxhkdrc` добавлен свободный `super + alt + w`. Копия исходного sxhkdrc — рядом с суффиксом `.qubite-writing-20261005.bak`. Если sxhkd работает в другой сессии, выполнить `pkill -USR1 -x sxhkd` из своего терминала или перезайти в bspwm.
