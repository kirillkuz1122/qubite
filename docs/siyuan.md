# SiYuan на Raspberry

Личный SiYuan 3.8.6: https://siyuan.qubiteapp.online. Вход через существующий Qubite Auth, только настоящий `owner`. Ссылка находится в «Мои сервисы» и в Auth-хабе при выключенном основном сайте. Это один личный workspace; доступ друзьям не выдаётся через grants Memos/Vikunja.

## Использование

Открой ссылку в Zen или браузере телефона, войди своим аккаунтом Qubite. Сервер выдаст отдельную подписанную cookie SiYuan с `HttpOnly`, `Secure`, `SameSite=Lax`; второй пароль вводить не требуется. Не меняй системный пароль блокировки/API token без обновления интеграции: они нужны серверному входу и bridge.

Создавай блокноты, документы и вложенные страницы. SiYuan поддерживает Markdown, ссылки между блоками, таблицы и граф. Для совместной работы с Hermes используй блокнот **«Кирилл и Арчи»**. Остальные блокноты помощник не читает. Попроси его «найди заметку … в SiYuan» или «добавь … в общий блокнот».

На телефоне можно сохранить сайт на главный экран. Это браузерный доступ к тому же workspace. Нативные приложения SiYuan не подключаются непосредственно к Docker-серверу; бесплатную синхронизацию их отдельных локальных баз этим развёртыванием не обещаем. Сам веб-редактор использует интерфейс SiYuan, обрамление входа — Qubite.

## Управление и хранение

`/power` в управляющем Qubite-боте → SiYuan: выключение останавливает контейнер, данные сохраняются. Auth и управляющий бот работают независимо. Основной Qubite можно выключить, SiYuan продолжит работать.

- Контейнер `qubite-siyuan`, официальный ARM64 `b3log/siyuan:v3.8.6`.
- Только `127.0.0.1:6806`; Caddy 9288 + существующий HTTPS-туннель Cloudflare.
- Workspace: `~/services/siyuan/workspace`; приватный серверный код входа: `~/services/siyuan/private.json` (600), `container.env` (600).
- `GOMEMLIMIT=256MiB` и `GOGC=60` регулируют Go GC, **не являются жёстким лимитом всего контейнера**. На этой Pi memory cgroup выключен.
- Перед обновлением остановить контейнер, сохранить workspace и приватные конфиги в закрытый backup, затем поменять закреплённую версию. Не копировать `.sy` вручную между одновременно работающими базами.
- Например по SSH: `sudo docker stop qubite-siyuan`, `tar -C ~/services -czf ~/siyuan-backup.tar.gz siyuan`, `chmod 600 ~/siyuan-backup.tar.gz`, `sudo docker start qubite-siyuan`. Backup содержит секреты и заметки, не публиковать.

## Hermes и безопасность

Отдельный private stdio MCP `qubite-siyuan`, 7 инструментов: список, поиск, чтение, дочерние блоки, создание документа, дополнение, изменение конкретного блока. Bridge проверяет ID и принадлежность одному блокноту; SQL строится только в коде, пользователь не передаёт SQL, путь/URL/API endpoint. Нет delete/admin/внешних файлов и замены корневого документа. Нативный токен SiYuan технически широкий; ограничение реализовано bridge, токен остаётся в закрытом файле `~/.hermes/.qubite-siyuan.json`, не передаётся модели. Это не ОС-изоляция от владельца/программ с тем же Unix-пользователем.

Каждый внешний HTTP/WS запрос проверяет текущую сессию Qubite и owner. Нативная cookie или токен сами по себе не открывают публичный адрес. Изменения и WS требуют точный Origin SiYuan. Перед выдачей cookie проверяется owner и внутренний Caddy-ключ. Перенаправление допускает только origin SiYuan, без внешнего return URL. Прямой native API остаётся только локально.

Для полного выхода выйди из Qubite: кнопка блокировки самого SiYuan не завершает Qubite SSO и сервер может снова авторизовать владельца. Нативная cookie может жить 30 дней, но без действующей Qubite-сессии доступ всё равно закрыт. Веб-редактор имеет собственные функции плагинов/администрирования: владельцу они доступны; помощнику через MCP — нет.

Источники: [Docker/возможности](https://github.com/siyuan-note/siyuan), [API](https://github.com/siyuan-note/siyuan/blob/v3.8.6/docs/API.md), [нативная cookie-авторизация](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/model/session.go).

## Проверка развёртывания 09.10.2026

12 целевых Node-тестов, 18 Python deploy-тестов и 5 scope-тестов bridge прошли. На реальном Pi проверены UI/API/WebSocket владельца, запрет анонимного доступа/чужого Qubite-аккаунта/одной native cookie/чужого Origin, независимость при выключенном Qubite и stop/start через runtime. Реальный stdio MCP прошёл создание/чтение/добавление/правку; доступ к синтетическому чужому блокноту и замена корневого документа отклонены. Синтетические данные и временные сессии убраны.

После этих проверок SiYuan занимал около 95 МиБ PSS; было доступно 1445 МиБ ОЗУ и около 19 ГиБ диска, температура 46,9 °C, throttled=0x0. Это снимок после коротких проверок, не гарантия расхода на большой базе. Владелец ещё проверяет интерфейс телефона/Zen.
