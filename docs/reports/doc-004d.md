### Сделано

Добавлена корзина документов (DOC-004d, #201). В шапке документа — общая
кнопка с точечным значком «Удалить». Подтверждение открывается через `Sheet`:
«Документ уйдёт в корзину. Его можно вернуть». После локальной записи удаления
открывается список с заметкой «Документ в корзине · Вернуть».

В списке — `Segmented` «Документы / Корзина», переход через `Swap`.
Корзина объединяет локальные документы из `SyncClient.all()` с `listTrash()`.
Дубли убираются по ID; неотправленные локальные операции важнее сетевого ответа.
В строке — название, превью, дата удаления и «Вернуть». Есть загрузка, ошибка
с повтором, пустое состояние и пояснение об отсутствии сети. Документы из корзины
не открываются для редактирования.

Удаление и возврат используют `SyncClient.remove` / `restore`: изменения
записываются на устройство и отправляются обычной синхронизацией. Если сетевой
список опередил локальную копию, возврат сначала получает объект через sync.
Сервер и `packages/sync-client` не менялись.

Решил так, можно откатить: после возврата показываем «Документы» со сброшенным
поиском и фокусом на возвращённой строке; после удаления фокус — на быстром
«Вернуть». Для локального удаления дата берётся из времени операции,
для подтверждённой сетевой записи — из `deleted_at`.

Написаны сценарии Vitest для подтверждения, отмены, быстрого возврата, фокуса,
корзины, объединения без дублей, ошибок, запоздалого ответа, офлайна и повторного
открытия IndexedDB. Добавлены e2e на моке: создание → удаление → корзина → возврат
→ открытие с прежним текстом; быстрый возврат; очередь без сети и отправка при
подключении. ПК 1440×900 и телефон 360×780, светлая и тёмная темы, снимки
вложениям теста, проверки ширины и целей нажатия. Существующая конфигурация
запускает их также в Firefox, включая `firefox-mobile`.
