# ENG-007d: проверка «Английского»

Проверена версия PR #99 `7aeaf95cab608575726549736cfbb41a24bd733d` с поддельным API в Chromium. Экраны: ПК 1440×900 и телефон 360×780, светлая и тёмная темы. Снимки находятся в `docs/design/screens/ENG-007/`. В таблице для каждой основы имени есть четыре файла: `<имя>-light-pc.png`, `<имя>-dark-pc.png`, `<имя>-light-phone.png`, `<имя>-dark-phone.png`.

**Замечание по фокусу:** поставить фокус на «Спросить Нейта», нажать Enter, затем Escape. После закрытия активным становится `body`, а не кнопка открытия. Повторено во всех четырёх сочетаниях размера и темы; дополнительно проверено клавиатурой на телефоне. Это препятствует последовательной работе с клавиатуры.

Другие проверки: горизонтальная прокрутка в снятых состояниях не обнаружена. В длинном задании после прокрутки последняя кнопка видна над нижней полосой на ПК и 360 px в обеих темах. Размеры видимых кнопок в снятых состояниях — не менее 44×44 px; переключатели звука и вибрации — 52×44 px. При `prefers-reduced-motion: reduce` изменение `transform` у ошибочной пары не наблюдалось. Изменения CSS экрана используют токены; значения новых цветов заданы в файле токенов. Тёмная тема в снятых состояниях читаема, хотя неверные и уже соединённые пары выглядят приглушённо. Снимок неверной пары сделан во время краткого показа ошибки.

Проверка выполнена с моками, поэтому не подтверждает работу настоящего сервера или микрофона. Сборки и тесты на Pi не запускались; приёмка владельцем остаётся необходимой. Приложение и браузер после проверки остановлены.
