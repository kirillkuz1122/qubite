# ADR-0023 — выбранный Поток в рабочей оболочке

Статус: подтверждено прямым запросом владельца 13.10.2026. UI-001 перенёс палитру/типографику, но оставил физику до UI-002; владелец отклонил такое соответствие дизайну и потребовал использовать уже созданные живые элементы. Это исправление UI-001 и согласованная реализация UI-002. В том же сообщении разрешена следующая AUTH-007; вопросы по её экранам, новым документам и приглашениям отправлены, ответы ещё требуются по правилу владельца.

Перенести утверждённую механику из `assets/design-lab/src/milo/` и выбранные SVG из `flux/Marks.tsx` в `apps/web/src/material/`. Градуируется библиотека компонентов, не приложение-прототип, его аккаунты/моки или старые сервисы. Исходная витрина остаётся неизменной. [Карта исходников](../../design/MATERIAL_PROVENANCE.md). В последующих задачах использовать эти production-компоненты вместо новых независимых вариантов переключателей/ползунков/переходов.

1. Единственный активный профиль — Поток; палитра Игрушечная, Лента, Unbounded/Manrope. Не выбирать новый стиль вместо утверждённого. Действия оранжевые, выбор голубой, мысли жёлтые, положительные состояния зелёные; непрозрачный фон и читаемый текст.
2. Bounded drag/viscous return/edge deformation у действий и ссылок, пружинная ручка нативного range, перетаскиваемый switch, непрерывная подложка выбора/навигации, MorphContent и раскрытие/сборка диалогов. Native semantics/keyboard/точные значения сохраняются, drag/cancel не исполняет click/submit.
3. Перетекание по умолчанию503мс, сила100%; настройки силы/длительности/quiet/lite сохраняются только как косметические browser preferences. OS reduce и сила0 отключают motion. На coarse pointer lite включён по умолчанию; упрощает края/свет, сохраняет движение. Только один RAF scheduler для активных controls, после покоя работы нет; DOM/React не обновляются на каждом physics frame.
4. Рендеринг адаптируется к телефону/планшету/desktop; смена маршрута не меняет agreed IA/фиксированный Command. Видимость остаётся демо-preview до UI-003, права только через core; анимация/выбранный цвет не grant.

Проверки: keyboard/mouse/cancel и Chromium touch events, mid-flight retarget, idle/reduced motion, обе темы/axe/разные размеры/VisualViewport, live authority negatives и полный legacy/core harness. Это browser emulation, не измерение FPS на физическом телефоне. User visual/device acceptance остаётся отдельной проверкой. Backend/OAuth/email/DB/deploy не меняются этим решением.
