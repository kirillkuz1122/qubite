# ADR-0024 — Лендинг, отдельный Qubite Auth и документы аккаунта

Статус: CONFIRMED13.10.2026 по трём ответам владельца; AUTH-007 bounded implementation. Заменяет pending вопросы UI-002. [Auth UX](../../design/AUTH_UX.md), [legal](../../legal/README.md).

1. Website без сессии показывает публичный лендинг, явная кнопка → отдельный экран Qubite Auth; после настоящего входа обычная главная, owner Console только в настройках. Материал существующий Поток/Игрушечная/Лента/Unbounded/Manrope100/503, общие appearance/controls, а не новый набор кнопок.
2. Android открывает Auth в системном браузере. Native PKCE/broker/verified return и защищённое хранение AUTH-012/Android POC отдельно. Не передавать web cookies в приложение, не отдавать токены в произвольную deep-link ссылку. Desktop следует выбранному внешнему входу после своего POC.
3. Приглашения — ссылка и ручная вставка. Фиксированный /#/auth/register?invite=… — query **внутри fragment**, удаляемый до первого render/API. Только typed registration invitation. Email verify/reset имеют отдельную UUID+proof пару; открытие ссылки ничего не подтверждает, только явный POST. Старого входа по коду нет.
4. Полные новые terms/privacy/cookies/отдельное data consent подготовить. Реквизиты/юрисдикция/получатели/сроки неизвестны; publication_ready=false до заполнения и проверки. UI два самостоятельных choices, API пока package-level technical evidence; granular legal evidence до публичного deploy отдельно QUB-LEGAL-001. Не давать рекламе/AI права через регистрацию.
5. Сейчас один same-origin web artifact, hash routes /auth/*; core exact auth_origin/Host/cookies/CSRF сохраняются. Это отдельный **экран**, а не уже настроенный auth поддомен. Домен не выбран; ingress/SO cookies/SSO brokers для разных module origins проектировать в deploy/native задачах, без domain-wide session cookie или CORS обхода.
6. OAuth availability только server DTO; link/unlink — explicit own-password reauth. Browser navigate callback возвращает fixed303 /#/auth/complete либо /#/auth/linked; errors — fixed login с allowlisted generic code, без provider proofs/return_to. JSON API behaviour сохранён. UI заново читает me/access; callback URL не выдаёт доступ.
7. Live real same-origin API, demo build не отправляет credential/forms, не симулирует созданный аккаунт или письмо. Demo /welcome и /auth/login для просмотра с телефона; реальный public core deployment не выполнен.

Проверка — Chromium → Uvicorn → disposable PostgreSQL с synthetic users и injected memory-only mail; OAuth signed MockTransport отдельно. Это сильнее HTTP fixtures UI, но не SMTP/provider/физический Android/TLS ingress приёмка. Rollback — снять consumer/вернуть tested artifact, PostgreSQL UUID/пароли/consents не откатывать в старую SQLite.
