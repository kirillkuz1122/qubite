# ADR-0006: клиенты и комплект установки

CONFIRMED 12.10.2026: сайт на React/TypeScript; Android приложение; desktop сначала Linux с архитектурой для Windows/macOS; новый дизайн; обязательный deploy/ комплект и скрипт установки. Автодеплоя нет по ответу владельца. Реализация последовательная, не три полных клиента сразу.

Инженерный выбор для POC: общий React UI/контракты для сайта и desktop, Tauri 2 как desktop оболочка. Linux первый проверенный artifact; Windows/macOS требуют отдельных build runners, проверки OS adapters и подписей, не обещаем перенос одним переключателем. [Официальная документация Tauri](https://v2.tauri.app/start/) подтверждает поддержку web frontend и платформенных bindings, не качество нашей будущей сборки.

Android: Kotlin/Compose и нативный Ink для пера, локальная Room/файлы; React слой остальных экранов возможен после hybrid POC. [Android Ink API](https://developer.android.com/develop/ui/compose/touch-input/stylus-input/about-ink-api) — база для POC. Общие API/форматы/модель синхронизации обязательны, полное совпадение UI-кода необязательно. Никаких обещаний pressure/tilt/latency до устройства. Пользователь назвал Lenovo Xiaoxin Pad 2025 (фонетически); точные model ID, Android и модель пера фиксировать в probe.

Новый deploy/qubite2/ рядом с неизменёнными legacy installers: README, versioned manifests, env.example без секретов, ingress map, installer, upgrade/rollback, backup/restore. Выбор контейнеров/systemd и поддерживаемого server OS зафиксировать отдельным deploy specification POC; хостинг пока отложен. Installer различает fresh install и upgrade, не перезаписывает существующие данные/env/units, повторяемый запуск безопасен, dry-run/preflight, health и отчёт SHA. Скрипт готовится/тестируется в disposable окружении до production. Root deploy/install.sh остаётся legacy entrypoint до явного совместимого switch.

GitHub: исходный код, документация, CI и release artifacts. Рабочие БД, вложения, личные тексты, ключи и сессии туда не помещать. Выделенного backup storage сейчас нет; выбор отложен до данных/миграции. Пока можно тестировать backup/restore на synthetic fixtures. Production требует настоящего отдельного backup и restore проверки.
