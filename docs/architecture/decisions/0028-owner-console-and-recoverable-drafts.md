# ADR-0028 — Owner Console и восстанавливаемые черновики

15.10.2026. **CONFIRMED**: ответы владельца перед AUTH-004. Права каждому вручную без наборов; бюджет сначала показывает деньги за день/месяц, расход и резерв, остальные ограничения раскрываются. Явное сохранение со списком изменений. Несохранённое не должно теряться после случайной навигации или перезагрузки.

Инженерная реализация в этих границах:

- React Console в настройках, утверждённый Поток/Игрушечная. Пользователи, раздельные module/model grants, блокировка аккаунта и отзыв сессий с защитой singleton owner; каталожная visibility, бюджеты, регистрация/приглашения, аудит. Object ACL не выдаётся вместе с module entitlement: конкретные документы/пространства имеют отдельные права.
- Общий атомарный пакет изменений с session/CSRF/password reauth≤5min, If-Match по policy/budget/registration и UUID idempotency. Проверки из существующих stores переиспользуются внутри одной транзакции. Отказ любой команды откатывает всё. Миграция0011 добавляет только журнал пакетов; startup не применяет SQL.
- Черновик — минимальные изменения/введённые поля, owner UUID и исходная ревизия в localStorage этого origin/браузера. Синхронная запись при редактировании; ошибка хранилища явно показана. Не сохранять пароль, CSRF, cookie, API key, invite token, prompt или полный список пользователей. После logout он не открывается другому субъекту; восстановление только после нового серверного подтверждения owner. Это не резервная копия и не синхронизация устройств; очистка данных браузера удалит черновик.
- Восстановление не применяет изменения. Изменившаяся серверная ревизия требует явной сверки; stale draft не становится authority. Перед отправкой хранится неизменяемый пакет с UUID; потерянный ответ проверяется по receipt, повтор только того же пакета по явному действию. Успешный ответ очищает только соответствующий пакет; новые изменения не теряются.
- Создание invite — отдельное явное действие через AUTH-006. Токен показывается один раз и не хранится в черновике; при потерянном ответе исходный UUID позволяет отозвать invite, а не повторно выпустить незаметно. Общие login/maintenance/provider switches — AUTH-015; реальные ChatGPT funding/providers, SMTP, installer/deploy отдельно.

Проверки: real disposable PostgreSQL атомарность/CAS/idempotency/owner+CSRF+reauth/revoked sessions/no paid bypass; браузерные reload/navigation/conflict/lost response/storage failure/keyboard/mobile/другой аккаунт. Прототипные fixtures не реальная приёмка SMTP/устройств/production. Откат сохраняет0011 и новые записи; отключение consumer и forward fix без drop/reset.
