# Архитектурные решения (ADR)

ADR — короткая запись важного решения: контекст, варианты, выбор, последствия, как пересмотреть. Старые ADR не удаляются: если решение меняется, пишется новый ADR со ссылкой «заменяет NNNN».

Шаблон нового ADR:

```markdown
# NNNN. Название
- Статус: предложено | принято | заменено NNNN
- Дата:
## Контекст
## Варианты
## Решение
## Последствия
## Как пересмотреть
```
