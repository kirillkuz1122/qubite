# 0007. Порядок работы агента

- Статус: принято
- Дата: 2026-10-17
- Решения владельца: [D-008](../../product/DECISIONS.md), [D-020](../../product/DECISIONS.md), [D-021](../../product/DECISIONS.md)

## Решение

- Перед каждой задачей — вопросы владельцу; реализация после ответов.
- Коммиты на русском, без префиксов `feat:`/`fix:`, push сразу в `main` после зелёных проверок.
- Не пушить красный CI и не помечать задачу выполненной без проверки.
- Отчёт после задачи — простыми словами: что сделано, как посмотреть, что проверено, что не сделано.
- Подробности — [engineering/AGENT_WORKFLOW.md](../../engineering/AGENT_WORKFLOW.md).

## Как пересмотреть

Когда появятся другие участники или живой production нового Qubite — перейти на ветки и PR.
