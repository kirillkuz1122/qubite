# Экран истории документа (DOC-004c, #199)

В шапке открытого документа — «История». От 840 px список версий располагается
справа, выбранный снимок — в области документа. На телефоне используется общий
`Sheet` на весь экран; в просмотре переключатель сравнения и восстановление
закреплены внизу. Редактор остаётся подключённым к Yjs под просмотром.

Запросы списка и снимков, переименование и удаление выполняются через
`httpDocsTransport`. Именованные версии создаются через `DocStore.createVersion`:
сначала отправляются правки устройства. Восстановление — через
`DocStore.restoreVersion`, после отдельного подтверждения. Ошибки загрузки,
сохранения и восстановления остаются на экране, повтор доступен.

Решил так, можно откатить:

- По дням идёт обычный хронологический список, внутри дня именованные версии
  стоят первыми (D-818). Следующая страница использует `before` последней записи
  исходной страницы сервера, независимо от порядка показа.
- История запрашивается при открытии и возвращении сети. Офлайн список скрыт;
  скачанный в этой сессии снимок остаётся доступен для сравнения и восстановления.
- В сравнении направление — от выбранной версии к текущему документу. Счётчик
  считает изменённые, добавленные и удалённые блоки. Помимо цвета видны подписи,
  знаки `+` / `−`, зачёркивание и изменение состояния дела.
- На телефоне подтверждение заменяет содержимое того же `Sheet`: два модальных
  окна и две ловушки фокуса одновременно не открываются.
