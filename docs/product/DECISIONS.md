| D-051 | Один аккаунт и один сценарий входа для всех сервисов Qubite. Для расширений и агентов — отдельные отзываемые ключи с ограниченными правами. | CONFIRMED | [CX#60–63] |

| D-053 | Глобальный owner — один. Турнирные роли (`organizer`, `moderator`, турнирный `admin`) существуют только внутри модуля турниров. | CONFIRMED | [AC] |
| D-054 | Новый пользователь получает только аккаунт, профиль и настройки. Модули владелец выдаёт **вручную**. | CONFIRMED | [CX#123] |

| D-057 | Приглашения двух видов: на **конкретную почту** и **общая ссылка**. Одноразовые, со сроком (7 дней по умолчанию), отзываемые. Ввести приглашение можно по ссылке или вставкой кода. | CONFIRMED | [CX#146–147], [CX#213] |
| D-058 | Вход — только **после подтверждения почты**. | CONFIRMED | [CX#147] |
| D-059 | Как в старом Qubite, у владельца есть тумблеры: регистрация, вход, режим техработ, отдельные способы входа (OAuth-провайдеры), почта, глобальный запрет входа. | CONFIRMED | [CX#147], [CX#150] |
| D-060 | Способы входа: email + пароль, Google, Яндекс, VK, Telegram. Совпадение почты **не** объединяет аккаунты автоматически: привязка — из открытого аккаунта. | CONFIRMED / RECOMMENDED | [CX#96] |
| D-061 | Добавить вход через **ChatGPT**: такой пользователь может пользоваться AI в пределах своего плана ChatGPT; отдельно владелец может дать ему доступ к своему API. Официальный веб-вход OpenAI сейчас доступен только партнёрам — проверить условия при реализации. | CONFIRMED (как задача) | [CX#147–151] |
| D-062 | Права в Owner Console пока выдаются **каждому вручную**, без сохранённых наборов. | CONFIRMED | [CX#286] |
| D-063 | Изменения в Owner Console применяются **явной кнопкой «Сохранить»** со списком изменений. Несохранённый черновик не теряется при перезагрузке или случайном уходе (без паролей и секретов). Пароль подтверждается не чаще раза в 5 минут. | CONFIRMED | [CX#286–287] |

| D-077 | В Owner Console сначала показываем деньги за день и месяц, расход и резерв; остальные лимиты раскрываются. | CONFIRMED | [CX#286] |
