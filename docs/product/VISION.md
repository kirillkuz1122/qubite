# Видение и границы Qubite 2.0

CONFIRMED: единая персональная цифровая среда с будущими командами; общий аккаунт, связанные объекты, ручные сценарии без AI, local-first, self-hosting и переносимость данных. Исходное видение v1.1 полностью сохранено в QUBITE_MASTER_CONTEXT.md; обязательная корректировка owner/доступа — QUBITE_ACCESS_AND_OWNER_CONSOLE.md. Это целевой продукт, не описание готового кода.

Owner использует тот же Today/Docs/Projects UI. Настройки → Управление Qubite открывает отдельную Owner Console. organizer/moderator/admin существуют в Tournaments, не на уровне платформы. На старте один platform_owner, без тарифов/подписок; регистрация не выдаёт модули и AI автоматически.

Первый полезный релиз: ручная выдача Docs entitlement; заметка локально сохраняется, синхронизируется, связывается с проектом, находится через Command, меняется и восстанавливается из ревизии. Owner настраивает доступ/бюджеты; mock AI доказывает hard cap до любого платного провайдера. Tournaments/Search/Writing/VPN/Vault/Brief продолжают работать через прежние URL.

Ink — отдельный важный трек с ранним аппаратным исследованием; хороший UI не компенсирует задержку пера. MVP не включает все 48 идей, Studio, весь Finance/Life, real-time team collaboration или школьный API. Все они сохранены в [реестре](REQUIREMENTS.md), без ложной готовности.

Бесплатный базовый доступ RECOMMENDED: вход/профиль/свои сессии/пустая оболочка/список собственных грантов. Даже бесплатный Docs owner выдаёт вручную в первом срезе. OPEN QUESTION: нужен ли явный onboarding template автоматических бесплатных grants позже.

Продуктовая приёмка: владелец подтверждает UX реального сценария на ПК/телефоне; Ink на конкретном планшете. Сборка, тест или существование файла не заменяют такую приёмку.
