# 105. Агентная ОС, этап AOS-4 + 5d/5e: расписание, потолки, Recos (20.11.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md). Задача — [#282](https://github.com/kirillkuz1122/qubite/issues/282), план — [AGENTIC_OS.md §8](../../architecture/AGENTIC_OS.md). Макеты — [PULT.md](../../design/PULT.md), снимки Figma — [screens/AOS-4/figma](../../design/screens/AOS-4/figma/).

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-1090 | **Сервер расписание хранит и считает, но сам задачи не запускает.** Запускают Pi (тихие, лёгкие) и облачные сессии (тяжёлые, D-948); после запуска они шлют отчёт `POST /api/pult/schedules/runs` по токену сборщика (как D-980). Таблицы `pult_schedules` (определение) и `pult_schedule_runs` (журнал), миграция 0056. Платный ИИ на сервере не вызываем. | CONFIRMED | агент, можно откатить |
| D-1091 | **Потолок — токены и $ в неделю на задачу**, считается по журналу за скользящие 7 дней. С 80% шкала жёлтая, на 100% сервер сам ставит `paused` и задача попадает в «ждёт тебя» (D-958). Отчёт о запуске на паузе принимается, но запуск `GET /api/pult/schedules/due` не отдаёт. Снять паузу может только владелец (переключатель) — после этого счёт идёт дальше, потолок можно поднять. | CONFIRMED | агент, можно откатить |
| D-1092 | **Активная / тихая** — поле `kind`. Активная пишет в журнал всегда, тихая — только если что-то нашла (иначе «молчит, всё хорошо»). Таблица сортируется по токенам за неделю (по умолчанию), по времени, по имени. «Новая задача» — форма: имя, когда, где (Pi / облако), модель, потолок. | CONFIRMED | агент, можно откатить |
| D-1093 | **Recos живут в Пульте и нигде больше** (D-939): таблица `pult_recos` (миграция 0057), ничего во Входящие. Карточка — раздел ARMS (apps / routines / memory / skills / jokers), «что заметил», «что сделаю», усилие S/M/L, экономия (текстом), тронет файлы, статус `new → basket / no / later → applied`. Приходят одним `POST /api/pult/recos/report` по токену сборщика; повтор той же недели заменяет предыдущие карточки в статусе `new`. | CONFIRMED | агент, можно откатить |
| D-1094 | **«Применить выбранное»** — сервер собирает из корзины одну запись `pult_reco_batches` с текстом-заданием и статусом `queued`; сам ничего не пишет в GitHub (Пульт — только чтение, D-980). Задание забирает менеджер или владелец: `scripts/pult_recos.py batch` печатает его, дальше — обычная задача сессии и PR. Владелец вливает сам («твоё “да”», D-957). | CONFIRMED | агент, можно откатить |
| D-1095 | **Карточки делает пятничная задача «Пятничные Recos»** — навык `recos` (`.claude/skills/recos/`) в облачной сессии по подписке: читает сводку недели с сервера, делает 10 идей — 8 по образцам, 2 джокера «мимо образцов» (D-1084), и отправляет их `scripts/pult_recos.py send`. Платного ИИ на сервере нет; если понадобится — только через AI-шлюз с бюджетом. Удачный джокер владелец переводит в образцы сам. | CONFIRMED | агент, можно откатить |
| D-1096 | **Таблица для `/calibrate`:** `scripts/pult_recos.py calibrate` собирает `docs/harness/corrections.md` в таблицу «поправка · куда класть» (черновик — без решений: решает владелец, D-1082); пятничная задача кладёт её рядом с Recos. Это закрывает «отложено из AOS-1» (D-1086). | CONFIRMED | агент, можно откатить |
| D-1097 | **Вкладки Пульта:** к «Светофор / Агенты / Карта» добавляются «Recos» и «Задачи» (макет 47-5376, 48-6170); «Навыки» и «Память» — позже (D-985). На телефоне задачи — карточки (48-6450). Задача режется на два PR: расписание (0056), Recos (0057). | CONFIRMED | агент, можно откатить |
