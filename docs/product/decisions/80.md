# 80. Голосовой ввод (CMD-005, 05.11.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Сделала сессия задачи CMD-005 по D-268, D-299, D-451, D-686. Блок номеров D-760…D-762.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-760 | **CMD-005 разбита:** 005a — сервер (`POST /api/v1/inbox/voice`, настройка способа `voice_prefs`), 005b — кнопка записи и выбор способа в web (designer), 005c — свой ключ API, Android, локальный Whisper. Первая рабочая часть — 005a (#219). | CONFIRMED | агент, можно откатить |
| D-761 | **Способ распознавания хранится у человека** (`cloud` по умолчанию, `device`, `local`, `own_key`). Сервер сам распознаёт только `cloud` — через AI-шлюз (`Gateway::transcribe`, бюджет и журнал). `device`/`local` — клиент присылает готовый текст, `own_key` — 005c. На Pi не распознаём (D-686). | CONFIRMED | агент, можно откатить |
| D-762 | **Без гранта или при отказе шлюза голос не теряется:** аудио сохраняется вложением `voice.*`, во Входящих — «Голосовая запись» и причина простыми словами; позже текст можно дораспознать. | CONFIRMED | агент, можно откатить |
