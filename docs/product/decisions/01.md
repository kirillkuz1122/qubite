# 1. Перезапуск проекта (17.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-001 | Работу Codex не продолжаем. Его ветка `codex` остаётся архивом. Из неё берём **только решения** (дизайн и продуктовые ответы), а код и документацию пишем заново. | CONFIRMED | [CL] |
| D-002 | Причины перезапуска: не та архитектура для длинного горизонта; интерфейс «по ощущениям не тот»: анимации дёрганые, иконки и логотип слабые, тёмная тема плохая, питомцы не нравятся; README маленький и неинформативный; владелец часто не понимал, что делает агент. | CONFIRMED | [CL] |
| D-003 | **Backend — Rust.** Web — **React + TypeScript**. Desktop — **Tauri** (Rust-оболочка, внутри тот же React). Android — **Kotlin** для пера (Ink) и тяжёлых нативных частей, остальные экраны — общий React-интерфейс. Другие технологии решаем по ходу разработки. | CONFIRMED | [CL] |
| D-004 | Базы данных: на сервере **PostgreSQL + pgvector**, на устройствах — **SQLite** с синхронизацией. | CONFIRMED | [CL] |
| D-005 | **Все** старые Python-сервисы (Search, Specbot, Kwork, Writing и др.) со временем **переписываются на Rust** как модули нового Qubite. До этого старый код лежит в `legacy/` как образец. | CONFIRMED | [CL] |
| D-006 | **Турниры переписываются** и становятся модулем Qubite. Принцип работы сохраняется, к нему добавляются учебные сервисы в духе Quizlet (возможно, это отдельный модуль Learn). Приоритет **низкий**: задача стоит в конце плана, функционал пересмотрим с владельцем. | CONFIRMED | [CL] — заменяет D-104 |
| D-007 | Порядок MVP: **сначала Qubite Command + Inbox** («самое практичное»), затем Planner, Docs и Ink. Все четыре входят в MVP. | CONFIRMED | [CL] |
| D-008 | Git: коммиты и push сразу в `main` допустимы, агент работает один. Тесты и CI агент настраивает сам. | CONFIRMED | [CL] |
| D-009 | Домены владельца: **qubiteapp.ru** и **qubiteapp.online**. Сейчас старый Qubite крутится на Raspberry Pi через Cloudflare Tunnel на домене `.online`. Домен и поддомены задаются в установщике. | CONFIRMED | [CL] |
| D-010 | README — на русском, большой и наглядный: это первая страница на GitHub. Документация — на русском, код и API — на английском. | CONFIRMED | [CL], [MC] |
| D-011 | Исходные документы видения и переписка с Codex хранятся в `docs/context/` и в git. | CONFIRMED | [CL] |
| D-012 | Папка `assets/` (дизайн-лаборатория Codex) пока не используется; решение о ней владелец примет отдельно. Код из неё не копируем, чтобы не повторить те же ошибки. | CONFIRMED | [CL] |
| D-013 | В будущем будет модуль **Qubite Home**: умный дом на базе Home Assistant с установкой на Raspberry Pi. В комплекте идёт **Shade AI** как «мозг» автоматизаций. Qubite — его интерфейс: Shade AI не получает своего приложения и берёт данные из Qubite. Подробности — [QUBITE_HOME.md](../QUBITE_HOME.md). Не в MVP. | CONFIRMED (идея) | [CL] |
| D-014 | Shade AI остаётся на **Python** (окончательно — D-121). Владелец будет дорабатывать его вместе с Claude. Требование «только локально» будет пересмотрено: выбор за пользователем. | CONFIRMED | [CL] |
