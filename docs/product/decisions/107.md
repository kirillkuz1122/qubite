# 107. MOB-001: нижнее меню и высота экрана на телефоне (20.11.2026)

Индекс — [DECISIONS.md](../DECISIONS.md). Задача #287; контекст — D-1100…D-1106 ([106.md](106.md)). Устройство владельца — Android, Firefox, обычная вкладка.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-1110 | Нижнее меню: набор пунктов известен до первого кадра. Пока `/api/auth/me` в пути, берём подсказку `localStorage["qubite.owner"]` («в прошлый раз вошёл владелец»), которую пишет сам `useMe`; гость или не владелец стирают её. Причина бага: «Пульт» зависел от ответа сервера, меню рисовалось из 4 пунктов и достраивалось. Подсказка только для раскладки, права — на сервере. | агент, можно откатить | агент |
| D-1111 | Высота экрана: по умолчанию чистый `100dvh` (строку браузера при прокрутке ведёт сам браузер, без JS). Только пока открыта клавиатура (`visualViewport` короче окна больше чем на 80 px), в CSS-переменные `--app-vh`/`--app-kb` пишется её высота, раз в кадр. Анимировать высоту нельзя. | агент, можно откатить | агент |
| D-1112 | В `<meta viewport>` добавлен `interactive-widget=resizes-content`: Chrome Android тоже сжимает раскладку под клавиатуру, как Firefox. | агент, можно откатить | агент |
| D-1113 | Firefox для Android в Playwright не запускается (нет мобильного движка); проверяем Chromium с эмуляцией Android/iPhone и Firefox Desktop 360 px, в отчёте это отмечено. | агент, можно откатить | агент |
