|---|---|---|---|
| D-740 | **Сравнение карт для Челябинска (проверено 30.10.2026 по официальным страницам).** Яндекс: JS API бесплатно до 500 запросов в сутки; Геокодер, Матрица и Router API — по расширенной лицензии 226 200 ₽, сверх лимита 390 ₽ за 1000 запросов; бесплатные условия запрещают **сохранять** данные API (кэш маршрутов невозможен), требуют видимых копирайтов и кнопки «Открыть в Картах», при регулярном превышении лимита ключ блокируется навсегда; есть живые пробки. OSRM (публичный сервер): без ключа, бесплатно, 1 запрос/с, только разумное некоммерческое использование, без гарантий, без пробок, нужна ссылка на OpenStreetMap. Nominatim (адрес → точка): без ключа, 1 запрос/с на всё приложение, нужен User-Agent и кэш. GraphHopper: бесплатно 500 кредитов/день (один маршрут ≈ 1 кредит), только некоммерческое, нужен ключ; платно от ≈ 56–69 € в месяц за 5000 в день. 2GIS: публичной бесплатной квоты нет, демо-ключ на месяц, дальше подписка. Точность дорог и адресов в Челябинске у OSM достаточна для «минут в пути» без пробок; пробки есть только у Яндекса — но он платный. | CONFIRMED | агент, можно откатить |
| D-741 | **Выбор: открытые карты, сервер за интерфейсом провайдера.** Сейчас OSRM + Nominatim (ключей нет, цена 0 ₽). Нагрузка Qubite — одно-два десятка маршрутов в день на человека, это внутри 1 запроса/с; сервер держит общую очередь 1 запрос/с и кэш 24 ч (OSM-данные хранить можно). Свой OSRM на Pi не ставим: сборка по России тяжёлая (D-620). Яндекс/GraphHopper подключаются как другой провайдер по ключу владельца, если понадобятся пробки или своя нагрузка вырастет — код менять не придётся. Реальные ключи в git и в тесты не попадают; тесты — на заглушках без сети. | CONFIRMED | агент, можно откатить |
