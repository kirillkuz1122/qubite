# 30. ChatGPT по подписке (AI-005, 19.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-219 | **Провайдер `chatgpt` сделан** (Q-33; пересматривает D-214 вслед за D-215): официальный путь OpenAI для open-source клиентов (developers.openai.com/siwc/token-sharing-open-source, 19.10.2026), без выдачи себя за Codex.<br>— **за флагом** `QUBITE_AI_CHATGPT_ENABLED` (выкл.); вход — `qubite ai chatgpt login`: OIDC + PKCE S256 через системный браузер, возврат на `http://127.0.0.1:<порт>/auth/callback`, первая регистрация `client_id=dynamic_agent_client` + `agent_name_hint=Qubite`, выданный `oaiapp_…` и `ext_agent_host_id` установки хранятся и переиспользуются; scopes `openid profile email offline_access resource.invoke chatgpt.tokens.use.direct`; без `chatgpt.tokens.use.direct` подключения нет. ID-токен проверяется по `iss`, `aud`, сроку и `nonce` (получен напрямую по TLS — подпись не проверяем, OIDC Core 3.1.3.7);<br>— **токены — только зашифрованными** в базе (ChaCha20-Poly1305, ключ `QUBITE_AI_SECRET_KEY` вне базы); access обновляется за 5 минут до конца часа, refresh одноразовый (ротация), обновление под блокировкой строки; при `invalid_grant` и т. п. токены стираются → «войдите снова»; при сбое сети не стираются. Выход — отзыв refresh-токена у OpenAI;<br>— **запросы** — `POST https://api.openai.com/v1/responses`, `stream: true`, `store: false`, инструкции в `instructions` (системные сообщения маршрут отклоняет), `max_output_tokens` не передаётся (не поддерживается). Успех — только `response.completed`;<br>— **учёт:** платит подписка, поэтому 0 $; число запросов и токенов — в тех же лимитах, плюс защита от зацикливания (D-213). Модели подписки — в каталоге как `chatgpt:<модель>`, включает owner;<br>— **только для собственных запросов того, кто вошёл** (owner): запрос другого пользователя Qubite — отказ до отправки (делиться подпиской с другими нельзя);<br>— **лимит подписки** (`subscription_sharing_usage_limit_exceeded`) — ошибка `subscription_limit` «лимит подписки ChatGPT исчерпан…» с другими моделями на выбор, и 15 минут новые запросы к ChatGPT не уходят (время сброса OpenAI не сообщает). `…_usage_unavailable` / `…_user_unavailable` / 503 — «не ушёл», повтор; `…_not_eligible` — «нужен Plus или Pro»; 401 до потока — обновить токен и один раз повторить;<br>— на сервере без браузера — SSH-туннель на порт входа (`ssh -L 1455:127.0.0.1:1455`). | CONFIRMED (ответ владельца + на усмотрение агента) | [CL] |
