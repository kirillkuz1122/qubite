# 38. Owner Console (ACC-003, 19.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Владелец заранее разрешил делать без него, вопросы — Q-42…Q-44 в STATUS (выбраны безопасные варианты).

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-231 | **Где Console и кому видна:** отдельная комната `/console/<раздел>` (Платформа, Люди, Модули, AI, Журнал, Сервер) в стиле «Частиц»; вход — «Настройки → Управление Qubite» и кнопка на «Аккаунте» (только у owner). Первым открывается «Платформа» (вопрос Q-44). Гость — на вход (D-229); вошедший не-owner видит ту же страницу «Такой страницы нет», что и на любом неизвестном адресе, API отвечает 404. **Пульт техработ** переехал с «Аккаунта» в «Платформу» (уточняет D-227), «пилюля» owner ведёт туда. Новые адреса сервера: `GET/POST /api/owner/accounts`, `PATCH /api/owner/accounts/{id}`, `POST /api/owner/accounts/{id}/sessions/revoke`, `GET /api/owner/audit`, `GET /api/owner/server`, `POST /api/owner/confirm`. Почта уже занята — `409 email_taken`. | CONFIRMED (на усмотрение агента) | [CL] |
| D-232 | **Пароль для опасных действий — не чаще раза в 5 минут** (D-063): сервер помнит время подтверждения в самой сессии (`sessions.confirmed_at`, миграция `0022`), без свежего подтверждения отвечает `403 confirm_required`; Console тогда показывает окно «Подтвердите паролем» и повторяет действие. Пароль проверяется с теми же лимитами перебора, что и вход; только из браузера. **Опасные сейчас:** создать человека, заблокировать/разблокировать, закрыть все его сессии. Тумблеры, модули и доступ пароль не спрашивают (их уже сохраняет бот и команда; вопрос Q-42). Себя заблокировать и закрыть себе сессии через Console нельзя (ACC-12) — свои сессии на «Аккаунте». | CONFIRMED (на усмотрение агента) | [CL] |
| D-233 | **Как сохраняется:** черновик (D-063) — у **тумблеров платформы**: меняются в браузере, внизу «Изменено: N» → список «было → станет» → «Сохранить» одним пакетом с версиями (`PATCH /api/owner/platform`, всё или ничего). Черновик хранится в браузере по owner (`qubite.console.draft.<id>`), только известные тумблеры, переживает перезагрузку, вкладки одного owner видят его общим. Сервер ответил 409 — Console сверяется: что на сервере уже так же (потерялся ответ «сохранено») — тихо убирает, это и есть защита от двойного применения; изменённое кем-то ещё — показывает **три значения** (было, сейчас на сервере, ваше) и «Оставить моё» / «Взять с сервера». **Модули, доступ людям, AI** применяются сразу (каждое — одно действие с версией или идемпотентное); **AI** в Console пока — разрешённые модели и модель для задачи; ключи провайдеров, лимиты и расход — командой `qubite ai …` до AI-003 (Q-43). **Сервер** — базово: версия, сколько работает, миграция, люди, сессии, журнал; нагрузка, бэкапы, перезапуск — позже. **Журнал** — новые сверху по 50, «Ещё», фильтры по виду (вход, люди, платформа, модули и доступ, приглашения, AI), действия словами. | CONFIRMED (на усмотрение агента) | [CL] |
| D-234 | **Проверки ACC-003:** сервер — `tests/console.rs` (не-owner и гость — 404; без пароля — `confirm_required`, неверный пароль — 401, подтверждение живёт 5 минут; создать → войти → Docs установлен и выдан → видит только Docs → отозвать → пропал; блокировка закрывает сессии и вход; себя нельзя; журнал и фильтры, «Ещё»; сервер). Web — `draft.test.ts` (черновик, потерянный ответ, конфликт, хранение по owner); `console.spec.ts` на подделке `e2e/console-mock.ts` (не-owner, черновик и перезагрузка, конфликт вкладок, люди с паролем и доступом, журнал, модули, AI, сервер, нет горизонтальной прокрутки) — Firefox, Chromium, телефон 360×780; `real-server.spec.ts` — тот же сквозной сценарий на настоящем сервере (проверен локально). Снимки — `docs/design/screens/acc-003-*.png`. | CONFIRMED (на усмотрение агента) | [CL] |
