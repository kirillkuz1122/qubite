| D-190 | CMD-001, ответы владельца (18.10.2026):<br>— **разобранная мысль уходит в архив**, а не удаляется. Удалить — отдельно: в корзину, с отменой (вернуть). Удаление навсегда — позже, отдельной онлайн-операцией;<br>— **ручных тегов и папок во Входящих нет.** Qubite Command сам понимает, что это (дело, заметка, мысль к проекту, просьба к AI-агенту «сделай X»), и привязывает к нужным проектам. В модели заложено место под результат разбора; сам разбор — CMD-003 (правила) и CMD-004 (AI);<br>— экран «Входящие» в `apps/web` в этой задаче **не трогаем** (там идёт DS-002) — подключение экрана к серверу отдельной карточкой CMD-007; CMD-001 → `review`, пока экран не принят. | CONFIRMED | [CL] |
| D-191 | CMD-001, модель элемента (решения агента):<br>— элемент — объект ядра `inbox.item` (заголовок = первая строка, версия, корзина, история) + строка `inbox_items`: вид (`text`, `link`, `file`, `voice`), полный текст (до 20 000 символов), ссылка (`http(s)://`), источник (`web`, `desktop`, `android`, `telegram`, `api`), **время записи на устройстве** (будущее время устройства превращается в «сейчас»);<br>— статусы: `new` (ждёт разбора) и `archived` (разобрано или убрано в архив, с временем). Отдельного статуса `triaged` нет: «разобрано» = архив (D-190);<br>— разбор: `triage_status` (`pending` → `suggested` → `confirmed`, или `skipped`), намерение (`task`, `note`, `project_thought`, `agent_request`, `other`), подробности (кто разобрал — `rules`/`ai`/`person`, уверенность, краткая суть). Связи с проектами и другими объектами — обычные связи ядра типа `about` (источник `ai`/`system`/`manual`). Повторный разбор заменяет автоматические связи, а поставленные человеком оставляет. Связать можно только со своими объектами;<br>— `qubite_inbox::suggest` сохраняет предложение, `confirm` — человек принял: разобрано и в архив. Разбор с устройства (через синхронизацию) менять нельзя — только сервером. | CONFIRMED (на усмотрение агента) | [CL] |
| D-192 | CMD-001, синхронизация по HTTP (решения агента):<br>— `POST /api/v1/sync/push` и `GET /api/v1/sync/pull` — только после входа (cookie + CSRF или Bearer приложения) и через Policy Gate: операция в модуле без права `write` отклоняется с причиной **`forbidden`** (остальные в пакете применяются); `pull` отдаёт только модули с правом `read`. Повтор того же `op_id` возвращает прежний ответ, даже если права с тех пор выдали — устройство шлёт мысль новой операцией;<br>— протокол расширен **полями модуля**: `create.fields`, новая операция `patch` (только меняющиеся поля), `fields` в снимке. Поля проверяет модуль (`TypeFields`); если модуль отклонил поля — откатывается вся операция. Через HTTP синхронизируются **только типы с обработчиком** (сейчас `inbox.item`), остальное — «тип не синхронизируется»;<br>— обычные адреса `/api/v1/inbox` (список: новые/архив/корзина; записать; изменить; в корзину; вернуть) работают через тот же движок — одна проверка, одна история; повтор записи с тем же ID не создаёт дубль; устаревшая версия → 409;<br>— модуль `inbox` в каталоге теперь «установлен», готовность «бета»; доступ — по-прежнему только грантом (D-172);<br>— **известное ограничение:** если доступ к модулю выдали позже, старые объекты этого модуля, которые уже «за курсором» устройства, сами не придут — нужна полная пересинхронизация (сделаем вместе с экраном, CMD-007). | CONFIRMED (на усмотрение агента) | [CL] |
| D-193 | CMD-001, «есть новое» по WebSocket (решения агента):<br>— `GET /api/v1/sync/ws`: сервер шлёт `{"type":"ready"}` и `{"type":"changed"}` — **без данных**, данные устройство забирает через `pull` со своими правами. Нужно право `read` во Входящих;<br>— источник подсказок — **триггер базы** на каждое событие объекта (`pg_notify` с ID владельца) и один `LISTEN` на сервер: поэтому подсказку вызывают и синхронизация, и API, и будущий бот в отдельном процессе. При обрыве связи с базой — подсказка всем;<br>— права проверяются **перед каждым сообщением и каждые 30 секунд**; отзыв гранта или сессии закрывает соединение с кодом **4403**, клиент больше не переподключается;<br>— браузер может подключиться **только со своего сайта** (`Origin` = адрес сервера), иначе 403: иначе чужой сайт мог бы открыть соединение с cookie владельца;<br>— `@qubite/sync-client`: `captureThought`/`archiveThought`/`inboxItems` (мысль сначала на устройстве), `httpTransport` (CSRF из cookie или Bearer), `watchChanges` (WebSocket + событие `online`, переподключение с паузой до 30 с). | CONFIRMED (на усмотрение агента) | [CL] |
