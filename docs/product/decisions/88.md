# 88. Голосовой ввод (CMD-005, 05.11.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Сделала сессия задачи CMD-005 по D-268, D-299, D-451, D-686. Блок номеров D-844…D-847; CMD-005b добавила D-849…D-853, CMD-005c — D-854…D-858.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-844 | **CMD-005 разбита:** 005a — сервер (`POST /api/v1/inbox/voice`, настройка способа `voice_prefs`), 005b — кнопка записи и выбор способа в web (designer), 005c — свой ключ API, Android, локальный Whisper. Первая рабочая часть — 005a (#219, PR #222). | CONFIRMED | агент, можно откатить |

На Pi не распознаём (D-686). | CONFIRMED | агент, можно откатить |
| D-846 | **Без гранта или при отказе шлюза голос не теряется:** аудио сохраняется вложением `voice.*`, во Входящих — «Голосовая запись» и причина простыми словами; позже текст можно дораспознать. | CONFIRMED | агент, можно откатить |

| D-848 | **Выключатель будильника без Pi:** закрытый PR #89 — таймер не будит (работает со старым скриптом); открыть PR — включить. Владелец 5.11: CMD-005 доделать, потом пауза проекта, лимиты нужны на другое. | принято | владелец + [CL] |

| D-850 | **Очередь голосовых записей** (`VoiceQueue`, IndexedDB, своя у аккаунта) повторяет отправку при сети, 401, 403 и 5xx; после 400/404/409/413/415/422 запись остаётся с причиной и кнопкой «Удалить». | CONFIRMED | агент, можно откатить |

| D-852 | **Аудио вложения Входящих:** `GET /api/v1/inbox/{id}/audio` — владелец + право Read, поток с диска, mime только из списка аудио, `Accept-Ranges: none` (Range не поддержан). | CONFIRMED | агент, можно откатить |
| D-853 | **Настройка способа в web:** работают «Облако» и «Встроенное в браузер» (Web Speech, текст уходит полем `text`); «Свой ключ» и «Локально» показаны неактивными до CMD-005c. | CONFIRMED | агент, можно откатить |
| D-854 | **Свой ключ (`own_key`):** человек даёт ключ OpenAI-совместимого сервиса распознавания (OpenAI, Groq или любой с `/audio/transcriptions`); сервер хранит его только зашифрованным и клиенту не возвращает, платит человек сам, бюджет платформы не списывается. Без ключа или при отказе сервиса звук сохраняется (D-846). | CONFIRMED | агент, можно откатить |

| D-857 | **Если распознавание на устройстве не успело** (закрыли вкладку, Whisper молчит 60 с), запись в очереди ждёт не дольше 90 с и уходит одним звуком; причину «почему без текста» показывает то же устройство и на сервер её не отправляет. | CONFIRMED | агент, можно откатить |
| D-858 | **«Свой ключ» в web выключен флагом `OWN_KEY_READY`**, пока серверная часть (`/api/v1/voice/key`, задание Codex #226) не в `main`: вариант виден, но выбрать его нельзя («Появится в следующем обновлении»), форма ключа готова и включается одной строкой.
