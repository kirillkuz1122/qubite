# 88. Голосовой ввод (CMD-005, 05.11.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Сделала сессия задачи CMD-005 по D-268, D-299, D-451, D-686. Блок номеров D-844…D-847; CMD-005b добавила D-848…D-852.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-844 | **CMD-005 разбита:** 005a — сервер (`POST /api/v1/inbox/voice`, настройка способа `voice_prefs`), 005b — кнопка записи и выбор способа в web (designer), 005c — свой ключ API, Android, локальный Whisper. Первая рабочая часть — 005a (#219, PR #222). | CONFIRMED | агент, можно откатить |
| D-845 | **Способ распознавания хранится у человека** (`cloud` по умолчанию, `device`, `local`, `own_key`). Сервер сам распознаёт только `cloud` — через AI-шлюз (`Gateway::transcribe`, бюджет и журнал). `device`/`local` — клиент присылает готовый текст, `own_key` — 005c. На Pi не распознаём (D-686). | CONFIRMED | агент, можно откатить |
| D-846 | **Без гранта или при отказе шлюза голос не теряется:** аудио сохраняется вложением `voice.*`, во Входящих — «Голосовая запись» и причина простыми словами; позже текст можно дораспознать. | CONFIRMED | агент, можно откатить |
| D-847 | **Повтор записи с тем же ID** возвращает прежний результат (`inbox_voice_captures`), даже если человек потом правил текст; параллельные повторы вызывают шлюз один раз (блокировка по ID). Шлюзу — 15 с, дальше остаётся аудио. | CONFIRMED | агент (Codex), можно откатить |
| D-848 | **Запись в web:** кнопка освобождается сразу после сохранения на устройство, распознавание идёт в фоне. Запись короче 0,5 с не отправляется, битрейт 32 кбит/с, предел 120 с. Формат webm/opus, на Safari mp4. | CONFIRMED | агент, можно откатить |
| D-849 | **Очередь голосовых записей** (`VoiceQueue`, IndexedDB, своя у аккаунта) повторяет отправку при сети, 401, 403 и 5xx; после 400/404/409/413/415/422 запись остаётся с причиной и кнопкой «Удалить». | CONFIRMED | агент, можно откатить |
| D-850 | **Причину «без текста»** пока помнит устройство (30 дней): список Входящих её не отдаёт. Отдавать с сервера — отдельная задача, если нужна на других устройствах. | CONFIRMED | агент, можно откатить |
| D-851 | **Аудио вложения Входящих:** `GET /api/v1/inbox/{id}/audio` — владелец + право Read, поток с диска, mime только из списка аудио, `Accept-Ranges: none` (Range не поддержан). | CONFIRMED | агент, можно откатить |
| D-852 | **Настройка способа в web:** работают «Облако» и «Встроенное в браузер» (Web Speech, текст уходит полем `text`); «Свой ключ» и «Локально» показаны неактивными до CMD-005c. | CONFIRMED | агент, можно откатить |
