# 8. Хостинг, устройства, пользователи (17.10.2026, второй раунд)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-110 | Qubite **не привязан к Raspberry Pi**: возможны VPS, свой сервер или домашний ПК. Ресурсами не ограничиваемся, но всё оптимизируем; ориентир — чтобы базовый набор умещался в **2 ГБ RAM**. | CONFIRMED | [CL] |
| D-111 | У владельца **Raspberry Pi 5 (4 ГБ)** — подходит для личного/тестового использования. SSH к нему сейчас не работает (не отвечает и через Tailscale), поэтому деплой пока без него. | CONFIRMED | [CL] |
| D-112 | **Универсальный установщик одной командой:** сам скачивает и ставит всё нужное (сервер, PostgreSQL, Caddy, туннель, выбранные модули, включая VPN), обновляется сам, с понятной документацией: что ставится, какие сервисы запускаются, как всё работает. | CONFIRMED | [CL] |
| D-113 | PostgreSQL по умолчанию ставится **на том же сервере**; установщик позволяет указать **внешнюю БД** (адрес/строку подключения), если она будет куплена отдельно. | CONFIRMED | [CL] |
| D-114 | Телефон владельца — **Redmi 12** (слабое железо: эталон плавности). Основной браузер — **Firefox**: всё обязано полностью работать в Firefox (desktop и Android). | CONFIRMED | [CL] |
| D-115 | Планшет — **Lenovo Xiaoxin Pad 2025** (диагональ уточнить: 11″ или 12.1″). Возможности пера определит диагностика INK-001. | CONFIRMED (модель) / OPEN (вариант) | [CL] |
| D-116 | Папку `assets/` (лаборатория Codex) удалить и сделать **новую дизайн-лабораторию** в задаче дизайна: владелец смотрит, даёт обратную связь, утверждает. | CONFIRMED | [CL] |
| D-117 | **Любое название обосновывается идеей Qubite**: почему так называется, за что отвечает, как себя ведёт. «Просто так решили» не принимается. Относится к помощникам, модулям, функциям. | CONFIRMED | [CL] |
| D-118 | Имена Луми/Кип/Пип/Сэйдж не нравятся — нужны новые концепции с обоснованием (см. [COMPANIONS §2](../../design/COMPANIONS.md)). | CONFIRMED | [CL] |
| D-119 | Сейчас Qubite — **для себя** (и максимум для друзей, которым владелец сам настроит доступ). Причина создания: устал платить Notion и другим закрытым сервисам, которые могут перестать работать; хочет всё в одном месте, чтобы у агента был весь контекст. Доступы — только ручные настройки, бесплатных наборов по умолчанию не нужно. | CONFIRMED | [CL] |
| D-120 | Подписки, пробный период и бизнес-модель — **позже**, когда Qubite будет развиваться как бизнес. Архитектура это допускает, но сейчас не делаем. | CONFIRMED | [CL] |
| D-121 | Shade AI **остаётся на Python** (владелец знает Python и защищает проект). | CONFIRMED (заменяет OPEN в D-014) | [CL] |
| D-122 | Qubite Home ставится **отдельным установщиком**, не по умолчанию: только если у человека есть свой сервер/Raspberry Pi рядом с домом (нужен локальный хаб: Zigbee, Wi-Fi). На него ставятся Home Assistant, Shade AI и локальный AI; затем Qubite Home подключается к Qubite как модуль. | CONFIRMED | [CL] |
| D-123 | Shade AI — отдельный агент **без маскота**: «тень», которая делает всё незаметно. Видна максимум через уведомления (например, с извинениями или сбором обратной связи), и они стилизованы «под тень». | CONFIRMED | [CL] |
| D-124 | Перехват уведомлений телефона — **в приложении Qubite** с настройкой доступов (отдельного приложения Shade AI нет). | CONFIRMED | [CL] |
| D-125 | Как у VK (одно большое приложение + отдельные ярлыки): у модулей могут быть **отдельные иконки-ярлыки**, которые открывают основное приложение сразу в нужном модуле. Модули загружаются **по мере необходимости**, а не все сразу (и в клиенте, и на сервере). | CONFIRMED (идея) | [CL] |
| D-126 | Возможно: в Qubite можно добавлять **свои серверы и устройства** и распределять между ними нагрузку; агент выполняет задачи на другом устройстве (например, открывает Photoshop на ПК через MCP, если тот онлайн). Список идей — [IDEAS.md](../IDEAS.md). | IDEA | [CL] |
| D-127 | Все старые модули/сервисы **переделываются** (не переносятся как есть) — подтверждено ещё раз. | CONFIRMED | [CL] |
| D-128 | **Эталоны модулей** (на что опираемся при доработке): Command — Raycast и TextExpander; Planner — Sunsama и Akiflow; Finance — YNAB и Quicken; Writer — Grammarly (улучшаем текущую проверку на LanguageTool); турниры/учёба — Quizlet. Подробно — [IDEAS §3](../IDEAS.md). | CONFIRMED | [CL] |
| D-129 | Будет модуль **Reader** по образцу Readwise Reader: библиотека книг, статей, PDF и видео, выделения превращаются в карточки повторения. | CONFIRMED (идея модуля, не в MVP) | [CL] |
| D-130 | Планшет — **Xiaoxin Pad 2025, 11″**, стилус **Lenovo Stylus Pen** (серый, боковая кнопка, зарядка USB-C; совместим с Xiaoxin Pad 2025/2024 — TB335FC, TB331FC; ~2 500 ₽). | CONFIRMED (уточняет D-115) | [CL] |
| D-131 | Имена помощников — концепция **D «Атом Qubite»**: Элик (электрон, ловит мысли), Прото (протон, проекты), Нейт (нейтрон, мудрец), Фоти (фотон, личное), Shade (тень, без тела). Остальные концепции (C2, E) сохранены как запасные — владелец может передумать. | CONFIRMED | [CL] |
| D-132 | Версии: всегда **стабильные** выпуски. Rust — текущий stable (на 17.10.2026 — 1.99), закреплён в `rust-toolchain.toml`. PostgreSQL — **18** с **pgvector 0.8.7** (самая новая версия, для которой есть pgvector). | CONFIRMED | [CL] |
| D-133 | Web: **Vite + React 19 + TypeScript**, без Next.js. JS-пакеты — **pnpm** на Node.js. Bun рассмотрен: быстрее как установщик пакетов, но Playwright и Tauri официально рассчитаны на Node, а серверная часть Bun нам не нужна (сервер на Rust). К Bun можно вернуться без переделки кода. | CONFIRMED | [CL] |
| D-134 | Браузерные тесты — **Firefox и Chromium** обязательно. | CONFIRMED | [CL] |
| D-135 | PostgreSQL для разработки и тестов — **в Docker** (`scripts/dev-db.sh`), как и в CI. В систему не ставим. | CONFIRMED (на усмотрение агента) | [CL] |
| D-136 | Утечка `VPN_APP_TOKEN` старого VPN — **риск принят владельцем**: VPN нигде не запущен (у Raspberry нет белого IP), токен только проверяет само приложение, без аккаунта не войти, приложение нерабочее. Ничего из репозитория не убираем, историю не чистим. | CONFIRMED | [CL] |
| D-137 | Приватность репозитория — **открытый вопрос владельца**. Рекомендация агента: приватный до первой пригодной к использованию версии, затем открыть с чистым README и лицензией. Агент сам видимость не меняет. | OPEN | [CL] |
| D-138 | Репозиторий GitHub **сделан приватным** 17.10.2026 (заменяет OPEN в D-137). Открыть — отдельным решением владельца к первой рабочей версии. Учитываем лимит минут GitHub Actions для приватных репозиториев: проверки запускаются только при изменении своих файлов. | CONFIRMED | [CL] |
