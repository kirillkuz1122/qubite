| D-650 | **Источник — GitHub Issues токеном сервера.** `QUBITE_GITHUB_TOKEN` только в окружении сервера (`.env` на Pi), в git и в браузер не попадает; без него раздел честно пишет «не настроено». Репозиторий — `QUBITE_GITHUB_REPO` (по умолчанию `kirillkuz1122/qubite`), прокси — `QUBITE_GITHUB_PROXY` / `QUBITE_PROXY`. Один запрос за всеми открытыми issues и PR (до 300), снимок в памяти 3 минуты; «Обновить» перечитывает, если снимку больше 20 с. Ошибка GitHub — понятный текст (502), а не пустой экран. | агент, можно откатить | D-643 |
| D-651 | **Метки → группы.** `вопрос` — «Ждёт тебя»; `review` — «Готово — проверь» (важнее `in_progress`); `in_progress` — «Идёт»; `ready` — «Очередь» по номеру issue (порядок постановки); `лимит` — расход лимита. Только открытые issues. | агент, можно откатить | HAR-002 |
| D-652 | **Формат вопроса:** issue с меткой `вопрос`; текст до первого списка — вопрос, пункты списка (`-`, `*`, `1.`) — варианты, до 8; первый — рекомендация (оранжевая кнопка, дописывается «рекомендую»). | агент, можно откатить | HAR-002 |
| D-653 | **Ответ — одним нажатием, без пароля.** Вариант — кнопка, сразу комментарий «Ответ владельца: …» в issue и снятая метка `вопрос`; есть и поле «свой ответ». Пароль не спрашивается: это не опасное действие, ошибку владелец поправит новым комментарием. Сервер пишет только в открытый issue с меткой `вопрос` (иначе 409), ответ до 2000 знаков, запись `work.question_answered` в журнале Console. | агент, можно откатить | HAR-002 |
