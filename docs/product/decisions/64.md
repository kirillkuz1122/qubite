# 64. Живой голос Нейта через подписку ChatGPT (ENG-005, 25.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-590 | **Как устроено:** сервер (`POST /api/v1/english/realtime`) просит у OpenAI временный ключ (`POST /v1/realtime/client_secrets`, живёт 2 минуты) **по подписке ChatGPT самого человека**; браузер с ним подключается к модели напрямую по WebRTC (`/v1/realtime/calls`). Звук через Pi не идёт. Основной токен подписки в браузер не попадает; просроченный токен сервер обновляет сам (401 → обновить и повторить один раз). | CONFIRMED | [CL] (D-573) |
| D-591 | **Нейт тот же:** `tutor::VOICE_PROMPT` — характер и правила ENG-001 (строгий, язвительный, без мата, называет ошибку, «Say it again: …», ждёт повтора), но ответ голосом, без JSON; плюс урок, правило уровня и строгость (ENG-002), заметки «Английский.md», прошлые реплики разговора — данными через защиту AI-шлюза. Нейт начинает сам — с вопроса урока. | CONFIRMED | [CL] |
| D-592 | **Учёт в AI-шлюзе:** выдача ключа — обычный вызов (`ai_calls`, `paid_by = subscription`, 0 $): права, защита от зацикливания, лимиты запросов, журнал. Свои лимиты — таблица `ai_realtime_sessions`: сеанс до 15 мин, 60 мин и 20 разговоров в день на человека (`QUBITE_AI_REALTIME_MAX_MINUTES`, `…_DAY_MINUTES`, `…_DAY_SESSIONS`). Длительность сообщает браузер (без пауз), но не больше, чем прошло по часам сервера, и не больше потолка; не закрытый сеанс считается по худшему случаю. | CONFIRMED | [CL] |
| D-593 | **Расшифровка:** обе стороны — на экране по мере речи (события канала данных); готовые реплики по порядку уходят на сервер (`/realtime/{id}/lines`) в тот же разговор, что у ElevenLabs: история, опыт за реплики, итог в «Английский.md» по «Закончить». Повтор той же реплики не пишется (ID элемента OpenAI). | CONFIRMED | [CL] |
| D-594 | **Переключатель** в «Английский → Настройки»: «Голос разговора: ChatGPT — живой / ElevenLabs». Не выбран — сам: ChatGPT, если подписка подключена и провайдер включён, иначе ElevenLabs. ElevenLabs-путь не тронут и остаётся запасным; любая ошибка живого голоса предлагает «Говорить через ElevenLabs». | CONFIRMED | владелец, 25.10 |
| D-595 | **Модель и голос:** по умолчанию `gpt-realtime-1.5` (проверена на подписке владельца), на выбор — `gpt-realtime-mini`; если подписка mini не пустит — сервер сам берёт 1.5 и говорит об этом. Голоса OpenAI: marin (по умолчанию), cedar, ash, ballad, coral, echo, sage, shimmer, verse, alloy. Расшифровка речи человека — `gpt-4o-mini-transcribe` внутри сеанса (без языка: можно и по-русски). | CONFIRMED | [CL] (Q-146) |
| D-596 | **Сеть:** ключ выдаёт сервер тем же клиентом ChatGPT, что и остальные запросы подписки (`QUBITE_CHATGPT_PROXY` / `QUBITE_PROXY`, на Pi — напрямую через системный VPN). Браузер подключается к `api.openai.com` сам; не достучался или OpenAI ответил «страна не поддерживается» — ошибка с советом включить VPN на устройстве или выбрать ElevenLabs. Ретранслятор звука через сервер не делаем (Q-145). | CONFIRMED | [CL] |
| D-597 | **Экран:** «Начать разговор» → «Пауза / Продолжить» (микрофон и Нейт молчат, время не идёт), «Перебить», «Закончить», можно написать текстом в тот же разговор, «Осталось N мин». Понятные ошибки: ChatGPT не подключён (ссылка «Подключить ChatGPT»), лимит подписки, свои лимиты на сегодня, нет доступа к OpenAI, нет микрофона, время вышло. | CONFIRMED | [CL] |
| D-598 | **Диктовка — общий модуль** (просьба управляющей для ENG-006, 25.10): «скажи → получи текст» в любом поле ответа. Основной путь — своя подписка ChatGPT: сеанс OpenAI Realtime только распознавания (`gpt-4o-mini-transcribe`, модель `chatgpt:gpt-4o-mini-transcribe`, до 2 минут, WebRTC напрямую); запасной — запись и ElevenLabs на сервере (`/english/transcribe`). Учёт — в `ai_realtime_sessions`: в «разговоров в день» не входит (в уроке их много), секунды — в «минут в день». Web — `english-dictation.ts` (`startDictation`, `useDictation`). | CONFIRMED | [CL] |
