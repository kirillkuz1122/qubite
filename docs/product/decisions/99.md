# 99. Command с диспетчером (AOS-5h, 20.11.2026)

Индекс — [DECISIONS.md](../DECISIONS.md). Задача — [#272](https://github.com/kirillkuz1122/qubite/issues/272).

| #      | Решение                                                                                                                                                                                                                                                                                                                                                                                     | Статус   | Источник              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------- |
| D-1040 | **Строка Command отправляет обычный текст владельца диспетчеру.** На сервере нужны аккаунт владельца, право записи в модуле «Агент» и право пользоваться AI. Явные команды, поиск и выбор раздела работают через прежние действия строки. Сортировщик `command.dispatch` выбирается отдельно в Owner Console. Для ответов можно выбрать `command.answer`.                                   | PROPOSED | агент, можно откатить |
| D-1041 | **Сводку дня собирает сервер.** Берёт дела с датой на сегодня, сессии, открытые PR, вопросы владельцу и расход из Пульта. К вопросу добавляет сокращённый пересказ до шести сообщений этого дня по часовому поясу платформы. Исправления владельца хранятся отдельно от пересказа и служат примерами для сортировщика.                                                                      | PROPOSED | агент, можно откатить |
| D-1042 | **Поручение создаёт дело или ставит агенту сообщение в очередь.** Для запуска агента Пульт оценивает долю недели по верхней стоимости сопоставимой сессии и сводке текущего окна. Если доля больше 5%, данных недостаточно или выбрана Opus/Fable, требуется «да». Повтор с тем же ID, текстом, источником и `confirm: true` запускает сохранённое поручение один раз, на модели из оценки. | PROPOSED | агент, можно откатить |
| D-1043 | **«Ответить» пишет комментарий через Command.** Сервер извлекает номер и текст из «ответить на #N: …» и пользуется тем же обработчиком открытых вопросов GitHub. Пульт обращается к прежнему маршруту только при отказе шлюза до записи комментария.                                                                                                                                        | PROPOSED | агент, можно откатить |
| D-1044 | **«Открыть сессию» показывается по ссылке HTTP(S) из сводки сборщика.** Ссылки «Открыть задачу» и PR доступны по прежним данным. У сервера нет управления сессией, поэтому кнопка «Остановить» из макета не входит в задачу (уточнение D-987).                                                                                                                                              | PROPOSED | агент, можно откатить |
| D-1045 | **На телефоне окно становится полноэкранным со второго сообщения в беседе, на ПК растёт по кнопке или при длинном ответе.** Мысль даёт тост с исправлением «Это вопрос». Исправление может дать новый ответ или запись во Входящих. Уже созданные дела, мысли и отправленные поручения сохраняются. Голос использует тот же диспетчер после распознавания.                                  | PROPOSED | агент, можно откатить |
