# 76. Календарь — отдельный раздел (CAL-001, 29.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Сделала сессия задачи CAL-001 по D-423. Правила стиля — [DESIGN_SYSTEM §0](../../design/DESIGN_SYSTEM.md).

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-720 | **Событие — новый объект** `calendar_event` (не дело): название, заметки, начало и конец (UTC, миллисекунды) или «весь день», место, проект (необязательно), повтор. Хранится в своей таблице (миграция 0040), права — владелец. | агент, можно откатить | CAL-001 |
| D-721 | **Календарь собирает три источника** в одном ответе `GET /api/calendar?from=&to=`: события, дела с `due_time` (и без времени — как «весь день»), уроки из «Расписание.md». Повторы разворачивает сервер в окне запроса; уроки только читаются, правятся в файле. | агент, можно откатить | CAL-001 |
| D-722 | **Повтор события** — тот же формат, что у дел (`Recurrence` из `qubite-planner`), без нового формата. Правка «только это» и «всё» — вторым этапом, пока правится вся серия. | агент, можно откатить | CAL-001 |
| D-723 | **Три вида** — день · неделя · месяц (`Segmented` + `Swap`); шкала 00–24 с прокруткой к «сейчас», линия «сейчас» из точек цвета `--q-orange`; на 360 px вид недели показывает 3 дня, месяц — точки по дням. | агент, можно откатить | CAL-001 |
| D-724 | **Перетаскивание** — событие и дело со временем двигаются по шкале (шаг 15 минут) и между днями; урок не двигается. Сдвиг идёт тем же запросом правки, что и форма, с откатом. | агент, можно откатить | CAL-001 |
| D-725 | **Переход на летнее время пока не особый случай** (замечания Codex по PR календаря). Повторяющееся событие «весь день» считается фиксированной длительностью, а в час, который повторяется при обратном переводе часов, блок события на шкале сжимается до минуты. Часовой пояс владельца (UTC+5) без перевода часов, поэтому исправление — отдельной задачей, если появится пояс с летним временем. Право на расписание теперь проверяется до взятия соединения из пула (исправлено). | агент, можно откатить | CAL-001 |
