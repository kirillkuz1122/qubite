# 55. Программа английского (ENG-000, 22.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Владелец разрешил: где неясно — безопасный разумный вариант на усмотрение агента. Подробности — [content/english/README.md](../../../content/english/README.md), игра — [GAME.md](../../../content/english/GAME.md), исследование — [RESEARCH.md](../../../content/english/RESEARCH.md).

| D-510 | **Формат программы — JSON + JSON Schema (draft 2020-12) в `content/english/`:** `course.json` (уровни A0=Pre-A1, A1, A2, B1, B2 → модули → уроки по порядку), файл на урок `lessons/<уровень>/<id>.json`, `placement.json`, схемы в `schema/`. У урока: цель «После урока ты сможешь…» и can-do, слова с примерами, грамматика (`explain_ru` / `explain_en` / типичные ошибки / заметки агенту), фразы и темы разговора, 9 типов заданий (выбрать, пары, собрать фразу, перевести, вставить, послушать без текста, сказать вслух, описать картинку с промптом для генерации, ролевой диалог), своя домашка, критерии «пройден», связи для повторения. Глубина: `full` (A0, A1 — расписано целиком), `detailed` (A2 — образцовые задания, остальные агент генерирует), `outline` (B1–B2 — цель, грамматика, темы; урок дописывает агент). JSON — чтобы ENG-002 читал `serde_json` без новых зависимостей. Проверка — `scripts/check-english.mjs` (ajv: схема + связи) в `just check` и CI `english.yml`. | RECOMMENDED | агент |

Где хранить у человека — решает ENG-002 (таблица или файл рядом с «Английский.md»); в репозитории — только пример `overlays/example.json`. Слой — данные, не инструкции: прав агенту не добавляет. | RECOMMENDED | агент |
| D-512 | **Игра (D-502) — по [GAME.md](../../../content/english/GAME.md):** цель 5–30 мин/день (по умолчанию 10), считается только практика; огонёк — от 5 минут или урока/домашки, день отдыха 1 в неделю, заморозка 1/неделю сама (до 3) + за 7 дней подряд, пауза до 14 дней, вернуть погасший огонёк — двойная норма за 48 ч, лучший огонёк не пропадает; XP за действия (1–8, урок +20) с защитой от «фарма»; звания из атома (Кварк → Вселенная), не путать с уровнем языка; 3 задания дня по слабым местам + задание недели без лиг; ~17 достижений; 8 Частиц-помощников открываются учёбой и дают мини-режимы, не запирая учёбу; напоминание — Telegram/колокольчик не чаще раза в день, не в тишину, без вины. Ничего платного. | RECOMMENDED | агент |
| D-513 | **Объём и язык базы:** входной тест — 5 ступеней по 4 вопроса (3 из 4 — ступень пройдена, учиться с первой непройденной) + минута разговора (±1 ступень), уровень можно поправить (D-508); A0 — 12 уроков, A1 — 24 (целиком), A2 — 24 (подробно), B1 и B2 — по 24 урока планом; в каждом уровне итоговый урок-«босс» (монолог без подсказок, интервью). Язык репетитора по уровню (D-491): A0 — объясняет по-русски, английские фразы медленно; A1 — английский урока + русская опора; A2 — по-английски на A2, сложное по-русски; B1+ — только английский. Темы — для 14–15 лет: игры, программирование, олимпиады, Челябинск, школа, друзья. | RECOMMENDED | агент |
