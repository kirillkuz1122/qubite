Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Сделала сессия задачи DOC-002 по D-371, D-372, D-399, D-474, D-243. Блок номеров D-750…D-759.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-750 | **Разбивка DOC-002 на части:** a — сервер (yrs, хранение и обмен обновлениями, создание документа без сети, перенос старых Markdown, поиск); b — клиент `packages/sync-client/src/docs.ts` (Y.Doc в IndexedDB, обмен по векторам состояния, живое обновление); c — экран «Документы» (список, редактор Lexical, блоки); d — «в удалённый блок дописали — вернуть?» (Q-87). a, b, c идут параллельно по общему контракту из issue #64; d — после. | CONFIRMED | агент, можно откатить |
| D-751 | **Хранение и обмен:** у `docs_pages` появляется `ystate bytea` — полное слитое состояние Yjs (yrs на сервере, D-371). `GET /api/v1/docs/{id}/y?sv=<base64>` отдаёт недостающее устройству и вектор сервера; `POST /api/v1/docs/{id}/y` принимает обновление (base64, до 512 КБ; состояние до 4 МБ), сервер проверяет его через yrs и сливает. Повтор того же обновления ничего не меняет (свойство Yjs). После слияния сервер пишет событие ядра, и WebSocket «есть новое» будит другие устройства. Права — `docs` read/write, чужой документ — 404. | CONFIRMED | агент, можно откатить |
| D-752 | **Текст для превью и поиска присылает устройство** вместе с обновлением (`text`, Markdown, до 200 000 знаков, как D-474) и кладётся в `docs_pages.body`. Сервер не разбирает дерево Lexical: формат узлов Lexical — дело клиента и меняется с версиями 0.x. | CONFIRMED | агент, можно откатить |
| D-753 | **Старые документы (Markdown, D-474) переводит первое устройство:** пока `ystate` пуст, `GET …/y` отдаёт `seed_markdown`; устройство строит из него документ и шлёт `POST` с `seed: true` — сервер принимает его, только если `ystate` всё ещё пуст (иначе 409, устройство берёт готовое). Так два устройства не задвоят текст. | CONFIRMED | агент, можно откатить |
| D-754 | **Q-87 — вид блока хранится свойством:** все текстовые блоки — один узел Lexical `BlockNode` со свойством `kind` (`p`, `h1`, `h2`, `ul`, `ol`, `todo`, `quote`, `code`) и `checked`, `indent`. Смена вида меняет свойство, а не заменяет узел, поэтому дописанное на другом устройстве не теряется. Списки — плоские блоки с отступом (как в AFFiNE и Notion), без вложенных `ListNode`. | CONFIRMED | агент, можно откатить |
| D-755 | **Документ создаётся без сети** обычной операцией синхронизации `create` типа `docs.page` (у типа появляется обработчик полей в sync-server); текст Yjs уходит отдельно, когда объект уже есть на сервере. | CONFIRMED | агент, можно откатить |
| D-756 | **Поиск по документам (D-243):** `GET /api/v1/docs?q=` — полнотекстовый поиск PostgreSQL (`russian`, заголовок важнее текста) по своим документам, без AI. Command подключается к нему отдельной задачей. | CONFIRMED | агент, можно откатить |
