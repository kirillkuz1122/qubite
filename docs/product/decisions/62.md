# 62. Ответы владельца на Q-105…Q-107 (23.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-560 | **Картинки к «опиши картинку» — через подписку ChatGPT, а не за деньги** (Q-105: «у тебя же ChatGPT есть — его нельзя использовать?»). Провайдер ChatGPT ходит в Responses API, где есть инструмент генерации картинок; проверить, пускает ли его вход по подписке (Sign in with ChatGPT). Подписка — только для своих запросов (AI-005): картинка, нарисованная подпиской человека, хранится в его личном кэше; общий кэш на всех — только из платного ключа платформы. Не пускает — остаётся описание сцены (D-556). Отдельная задача ENG-004. | принято | владелец, 23.10 |
| D-561 | **«Английский» отдельным пунктом панели — вместе с NAV-001** (Q-106: «сам решай»); пока — «Агент → Английский». | принято | владелец, 23.10 |
| D-562 | **Голос во входном тесте — позже** (Q-107: «сам решай»): пока кнопки «Трудно / Нормально / Легко»; минута разговора с Нейтом — с ENG-004 или по отзыву после первых уроков. | принято | владелец, 23.10 |
| D-563 | **Как выбирается, чем рисовать картинку (уточнение D-560, владелец 23.10):** ① у человека подключён ChatGPT и он умеет рисовать → рисуем им **по умолчанию**, без вопросов (бесплатно, в счёт подписки); ② ChatGPT нет → **сначала спросить** человека: «Нарисовать картинку к заданию?» — и предложить на выбор: «Подключить ChatGPT» (бесплатно по своей подписке) или «Нарисовать через OpenRouter» с **примерной ценой** («≈ $0,04 за картинку») и **выбором модели** (список моделей картинок OpenRouter с ценой); «Не надо» — остаётся описание сцены. Выбор запоминается в настройках «Английского» (можно поменять). Деньги — через AI-шлюз и лимиты (свой ключ — свои лимиты, D-518; ключ owner — только если owner разрешил). Правило владельца: **«продукт делают детали»** (из нюансов строится система, а из системы — продукт) — такие развилки (чем платить, что по умолчанию, когда спросить) прописывать заранее. | принято | владелец, 23.10 |
