# 93. Вливание PR без траты лимитов (16.11.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Владелец 16.11: «слишком много токенов тратится на то, чтобы залить PR, дождаться, пока будет всё зелёное… запускать Haiku, чтобы он всё проверял». В тот же день слияние PR #240 разбудило подписанную на него сессию с контекстом 713 тыс. токенов.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-900 | **PR вливает скрипт, а не модель.** `scripts/land-pr.sh <PR>` (только REST, GraphQL из облака закрыт) ждёт CI и итог Codex-бота по последнему коммиту, при старом ревью пишет «@codex review», при зелёном вливает сквошем; при красном печатает упавшие тесты и замечания. Сессия запускает его в фоне и просыпается один раз. Подписки на события PR и будильники ради CI запрещены. Haiku (`scout`) — только выжимка большого лога; чинит код та сессия, что его писала (Haiku не знает задачу и не должен подгонять тесты). Менеджер перед своим слиянием чужого PR архивирует подписанную на него сессию. | CONFIRMED | владелец + агент |
