# 87. Управляющая сессия, 3.11.2026 (HAR-001)

Номера D-830…D-839. Сюда переехал D-690 из 68.md: номер D-690 занят ENG-007 (73.md).

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-830 | **Безопасность: вход не взломать, у каждой части минимум прав** (3.11, владелец). Раз Qubite заменяет вход и панели домашнего сервера, его вход должен быть надёжным (2FA, защита от перебора), а каждый модуль и сервис получает только нужные ему права: взлом маленького сервиса не должен давать доступ ко всей системе. Проверка — задача SEC-003 перед тем, как Qubite откроет наружу сервисы домашнего сервера. | владелец | HAR-001 |
| D-831 | **Задачи — строго по одной** (3.11, владелец: «по одной же мы задачи делаем»). Управляющая сессия держит одну сессию задачи; следующую запускает только после сдачи текущей. Параллельно — только служебные сессии на Pi (диагностика, установка). Заменяет «не больше 2–3 сессий» в MANAGER.md. | владелец | HAR-001 |
