# 98. Автоматическое обновление каталога моделей (AI-003, 20.11.2026)

Индекс решений — [DECISIONS.md](../DECISIONS.md). Задача — [#266](https://github.com/kirillkuz1122/qubite/issues/266).

| # | Решение | Источник |
|---|---|---|
| D-1030 | Сервер обновляет каталоги ChatGPT и OpenRouter в существующей фоновой задаче, по умолчанию раз в сутки. Если провайдер недоступен, остаётся последний полученный каталог до следующего обновления. | владелец |
| D-1031 | Новые модели подписки ChatGPT с `visibility: list` включаются с ценой 0 $. Исчезнувшие текстовые модели выключаются с сохранением записей. Каждое включение и выключение попадает в аудит. Ручное выключение сохраняется, пока модель остаётся в открытом списке. | владелец + агент, можно откатить |
| D-1032 | Фоновое обновление OpenRouter сохраняет выбор разрешённых моделей и обновляет каталог и цены. Начальная настройка списка OpenRouter по D-201 и D-210 сохраняется. | владелец + агент, можно откатить |
| D-1033 | Для `english.program` и `english.review` порядок выбора — модель, заданная владельцем для задачи, последний включённый ChatGPT Sol, общая модель AI-шлюза. Части версии сравниваются числами, поэтому 6.10 новее 6.2. Это обновляет выбор модели из D-486, D-501 и D-514. | владелец |
| D-1034 | Новая миграция снимает прежнее автоматическое назначение Sol из 0035. Назначения, сделанные владельцем, сохраняются. | агент, можно откатить |
