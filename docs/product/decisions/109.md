Индекс — [DECISIONS.md](../DECISIONS.md). Задача #289 (UI — задание Codex #306); решение владельца — D-1106 ([106.md](106.md)). Устройство владельца — Android, Firefox, обычная вкладка.

| # | Решение | Статус | Источник |
|---|---|---|---|
| D-1130 | Откуда «HAR-001 работает, HAR-002 готово»: Светофор брал статус из **меток открытых issue** (`in_progress` → работает, `review` → готово, вопрос → ждёт) без учёта времени. Забытая метка на старой задаче висела «работает» вечно. Сборщик на Pi, кэш GitHub (3 мин) и записи `pult_agent_state`/`pult_events` тут ни при чём: первый ещё не стоит (AOS-5j), второй короткий, а история Светофор не определяет. | агент, можно откатить | агент |
| D-1131 | Метки гаснут по времени. Последнее движение = позднее из «issue обновлён» и «последний ход живой сессии той же задачи». «Работает» — без движения > 12 ч гаснет; «готово/на приёмке» — > 48 ч; «ждёт тебя» (вопрос) — > 7 дней (вопрос ждёт именно владельца, поэтому дольше). Гаснет — значит задача уходит из Светофора и списка, issue не трогаем. Пороги — константы `ISSUE_*` в `pult.rs`. | агент, можно откатить | агент |
| D-1132 | Облачные сессии (AOS-5i, `scripts/pult_cloud.py`): архивные (`ARCHIVED`, `archived`, `archived_at`) в сводку не попадают; `COMPLETED` и `FAILED` отправляются как «закончили ход» (→ «готово», потом «тихо»), а не «работает».
