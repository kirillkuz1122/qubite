# 28. Публичный репозиторий и «Sign in with ChatGPT» (19.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-215 | Владелец решил сделать репозиторий **публичным** (ответ на Q-10) ради «Sign in with ChatGPT» для open-source. Публикует **сам владелец**, после чистки истории: школьная работа с ФИО и пакеты VPN с токеном — убрать (`git filter-repo`), `VPN_APP_TOKEN` — отозвать; остальное — по выбору (Q-35). Лицензия — Q-34, до ответа `LICENSE` нет. По документации OpenAI (19.10.2026): open-source и локальные приложения получают **модели по подписке** Plus/Pro через официальный `https://api.openai.com/v1/responses` с динамической регистрацией (`client_id=dynamic_agent_client`, адрес возврата только `http://127.0.0.1:<порт>/auth/callback`, без секрета) — для одного человека на его компьютере или его сервере (на сервере — вход через SSH-туннель, D-219). Это уточняет D-214. Вход «Войти через ChatGPT» на сайте для всех — только для партнёров (форма интереса).
