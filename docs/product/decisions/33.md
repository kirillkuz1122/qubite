# 33. Qubite Auth: экраны входа и юридические страницы (AUTH-005, 19.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Владелец заранее разрешил делать экраны без него в стиле «Частиц»; юридические тексты — черновиком (Q-06 открыт). Вопросы — Q-40, Q-41 в STATUS.

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-220 | **Адреса Qubite Auth** — те, что сервер уже пишет в письмах и редиректах: вход `/auth` (`?error=&provider=`, `?return_to=`, `?email=`), регистрация `/register?invite=`, письма `/verify-email?token=`, `/forgot`, `/reset-password?token=`, аккаунт `/account` (после привязки провайдера сервер теперь ведёт на `/account?linked=…`, было `/settings?linked=…`), «разрешить вход приложению» `/auth/device?client_id=…` (AUTH-006), документы `/legal/terms|privacy|cookies|consent`. Одна рамка на все страницы, **одна сборка сайта**: на поддомене `auth.` (D-034) те же адреса, разделение по хостам — в OPS-001. Возврат после входа — только путь на этом сайте (как проверяет сервер). Параметры адреса роутер читает **строками** (код `012345` и длинные `state` не портятся). Разделы приложения (`/today`…) гостю пока **не закрываем**: записи живут в браузере и уходят на сервер после входа (вопрос Q-40). | CONFIRMED (на усмотрение агента) | [CL] |
| D-221 | **Экран входа:** помощники группой (`Gang`) смотрят на каретку, **отворачиваются**, пока поле пароля в фокусе или пароль показан, грустят при ошибке, радуются при входе. «Я не робот» показывается только после ответа `captcha_required`/`captcha_failed`, токен одноразовый — после отказа виджет сбрасывается. Кнопки провайдеров — только **настроенные на сервере и включённые owner** (`/api/auth/oauth/providers` ∩ `login_methods`). Скрипты Turnstile, SmartCaptcha и виджета Telegram грузятся **только когда нужны** (Telegram — по нажатию), чтобы сторонние сервисы не узнавали о каждом, кто открыл страницу. Во время техработ экран входа пишет, что войти может только владелец паролем (D-218). | CONFIRMED (на усмотрение агента) | [CL] |
| D-222 | **Регистрация:** режим берётся из `/api/auth/registration` — «закрыта» честно говорит об этом, «по приглашениям» требует код (подставляется из ссылки), «открыта» без кода — показывает «не робот». **Галочка согласия** (условия + согласие на обработку данных по политике) обязательна, в том числе перед регистрацией через Яндекс/VK. Сервер отметку согласия пока **не хранит** — вопрос Q-41. После отправки — экран кода из письма; ссылка из письма подтверждает сама. «Прислать ещё раз» — не чаще раза в минуту. | CONFIRMED (на усмотрение агента) | [CL] |
| D-223 | **Аккаунт:** кто вошёл; «где вы вошли» — сессии и приложения коротко («Firefox на Android»), закрыть чужую, «выйти везде», «выйти здесь»; привязка и отвязка Яндекса/VK/Google и ссылка на Telegram-бота — **с паролем** (как требует сервер). В «Настройках» строка «Аккаунт» стала настоящей: имя или «Войти». | CONFIRMED (на усмотрение агента) | [CL] |
| D-224 | **Юридические страницы — черновики:** условия, политика конфиденциальности (по 152-ФЗ), cookies, согласие на обработку ПДн; на каждой пометка «Черновик», реквизиты оператора, контакты, место хранения и страны — «[…]» до ответа на Q-06. Cookies у Qubite **только необходимые** (`qubite_session`, `qubite_csrf`, `qubite_oauth`) — баннера согласия нет. Ссылки на документы — внизу каждой страницы Auth и в галочке регистрации. | DRAFT (ждёт Q-06 и юриста) | [CL] |
| D-225 | **Проверки AUTH-005:** e2e (Firefox, Chromium, Firefox 360×780) на подделанном сервере `e2e/auth-mock.ts` — те же адреса и ответы, что у настоящего: вход и ошибка, CAPTCHA после трёх неудач, провайдеры по тумблерам и ошибка провайдера, регистрация по приглашению с согласием и кодом, закрытая/открытая регистрация, ссылка из письма, восстановление пароля, аккаунт (сессии, бот, привязка VK), «разрешить вход» с возвратом после входа, документы. Отдельный сценарий **на настоящем сервере** — `e2e/real-server.spec.ts` (запуск по переменным, в `just e2e` пропускается; как поднять — DEVELOPMENT.md). Новые компоненты `packages/ui`: `Field` (поле с подписью, ошибкой, «показать пароль»), `Check` (галочка-согласие), `Note` (сообщение), `Gang` (помощники группой) — с тестами. | CONFIRMED (на усмотрение агента) | [CL] |
