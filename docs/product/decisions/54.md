# 54. Проект как папка (PROJ-001, 22.10.2026)

Индекс всех решений — [DECISIONS.md](../DECISIONS.md).

Владелец разрешил: где неясно — безопасный вариант на усмотрение агента, записать решением и вопросом (Q-102…Q-104). Код — `crates/qubite-planner/src/folder.rs`, `crates/qubite-server/src/projects.rs`, `apps/web/src/app/ProjectPage.tsx`.

| ID | Решение | Статус | Источник |
|---|---|---|---|
| D-470 | **Страница проекта** — адрес `/planner/project/<id>` (прямая ссылка), из Planner — кнопка **«Открыть проект →»** в раскрытой строке проекта (строка, как и раньше, раскрывается с делами — Q-102). Это часть раздела Planner, не новый пункт навигации. Сверху — заголовок: точка цвета проекта (она же значок), название, `#тег`, описание (поле `notes` проекта), «в архиве»; «Править» — окно `Sheet` (название, описание, цвет, статус), правка идёт синхронизацией — работает и без сети. Ниже вкладки через `Segmented` + `Swap`: **Задачи · События · Файлы · Память · Лента**. Данные — один запрос `GET /api/v1/projects/{id}`; дела и сам проект — из синхронизации, как в Planner. | CONFIRMED (на усмотрение агента) | [CL] |
| D-471 | **Задачи** — те же дела, что в Planner (синхронизация). Новое дело пишется прямо на странице и сразу ложится в проект; срок, время, важность и повторение понимаются, как в Command (разбор CMD-003; без дня — сегодня, Q-53). Отметка «сделано» и лента агента у дела — как в Planner. | CONFIRMED (на усмотрение агента) | [CL] |
| D-472 | **События — пока из дел:** отдельного объекта «событие» ещё нет (его добавит CAL-001). Вкладка показывает дела проекта со сроком **по дням** от сегодня («Просрочено» — сверху, сделанное в прошлом скрыто, «весь день» — раньше дел со временем). **Точка подключения для CAL-001:** поле `events` в ответе `GET /api/v1/projects/{id}` (сейчас всегда пустое, схема `ProjectEventItem`: id, title, date, time) и функция сайта `buildAgenda(tasks, events, today)` — CAL-001 кладёт туда события с `project_id`, экран менять не нужно. | CONFIRMED (на усмотрение агента) | [CL] |
| D-473 | **Файлы проекта** — готовые вложения ядра у объекта проекта: содержимое по хешу (`BlobStore`, папка `<QUBITE_DATA_DIR>/blobs` — та же, что у бота), одинаковый файл на диске один раз. До **25 МБ** на файл и **200** файлов в проекте; имя чистится (без папок и служебных символов), занятое — «отчёт (2).pdf». Загрузка — `POST /api/v1/projects/{id}/files?name=…` телом-файлом; кнопка «+ Файл» или перетащить. Скачивание: картинки и PDF открываются в браузере, остальное — только скачать (`application/octet-stream`, `nosniff`, `CSP sandbox`): чужой HTML или SVG с адреса Qubite не выполнится. «Убрать» — убирает из проекта сразу (строка в ленте); содержимое на диске остаётся (на него могут ссылаться другие), чистка неиспользуемого — позже. Вопрос — Q-104. | CONFIRMED (на усмотрение агента) | [CL] |
| D-474 | **Документы проекта — первая простая версия:** объект `docs.page` с текстом Markdown (миграция `0032_project_folder.sql`, таблица `docs_pages`, до 200 000 знаков), в проект входит связью ядра `part_of`, как дело; один документ может быть в нескольких проектах. На странице: «+ Документ» (название и текст), «Привязать документ» (свой из другого проекта), открыть — поправить название и текст (с версией: поменяли в другом месте — 409 и подсказка), «Убрать из проекта» (сам документ остаётся). Модуль `docs` помечен установленным (beta), права — `docs` read/write. Настоящий редактор (Lexical + Yjs, без сети) — DOC-002, он переведёт эти документы (Markdown переносится как есть). Раздел «Docs» пока прежний макет — Q-103. | CONFIRMED (на усмотрение агента) | [CL] |
| D-475 | **Память агента о проекте** — тот же файл «Проекты/<проект>.md» из папки агента (AGT-001, до 3 000 знаков), отдельного хранилища нет. Вкладка «Память» показывает его, «Править» — правка руками (строка ленты агента с откатом, как в «Записях»); нет файла — «Завести файл проекта». Без гранта на модуль «Агент» вкладка честно пишет, что агент выключен; данные проекта при этом видны. **Заметки агента (D-494):** когда агент раскладывает мысль во Входящих как заметку к проекту (CMD-004), её текст (до 300 знаков) строкой «Заметка: …» ложится в память проекта тем же пакетом, что и разбор, — «Откатить» убирает и её; файл полон — мысль всё равно разложена в архив. Без проекта — как раньше, только архив. Документом проекта заметка станет с DOC-002. | CONFIRMED (на усмотрение агента) | [CL] |
| D-476 | **Лента проекта — две части:** «Агент» — лента агента по проекту с «Откатить» (AGT-002) и «Изменения» — журнал событий ядра по самому проекту, его делам (пока дело в проекте; ушедшее — до ухода) и документам: создано, сделано, что поменялось (поля словами: «срок, время»), в корзине, файл добавлен / убран, документ в проекте / убран. Документ, созданный прямо в проекте, — одна строка «новый». | CONFIRMED (на усмотрение агента) | [CL] |
