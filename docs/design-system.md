# Дизайн сервисов

Визуальная основа — существующая тёмная Qubite: логотип из index.html, SVG из front/js/icons.js, Manrope для текста, Jura для заголовков и Space Grotesk для бренда. Розово-янтарный акцент, материалы glass-panel, верхняя полоса card-accent-top. Это интерфейс рабочих сервисов без рекламного hero.

Контент: в MyServices три статуса и действия; в AdminUsers — разрешения конкретного аккаунта и модалки лимитов; в поиске — запрос, результаты, короткое резюме и отдельный разговор с источниками. Настройки не занимают главный экран поиска.

Поведение: hover/focus существующих кнопок, штатные появления ops-view; reduced-motion отключает анимации. Иконки и логотип не заменяются текстовыми символами. Search Qubite theme синхронизирована с основными токенами; альтернативные темы и пользовательские цвета сохраняются отдельно.

Живой пример: `/design-system`. Там настоящие CSS-компоненты платформы, переключение темы, палитра, шкала 8/12/16/24/40/64 и варианты внутренних отступов 16/24/40. При изменении общих токенов проверить этот экран и search/static/app.css: поиск — отдельное приложение, поэтому токены пока копируются, а не импортируются общей сборкой.

Проверены desktop и ширина 390 px. В основных новых экранах горизонтального переполнения нет. Физическое автозаполнение AliasVault и особенности поисковых настроек разных мобильных браузеров проверяются отдельно на устройствах.
