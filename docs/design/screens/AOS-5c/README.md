# AOS-5c — Главная и вопросы Пульта

Снимки сделаны с кодом PR #268 (8597af1), во временной копии. Размер окна ПК — 1440 × 900, телефона — 360 × 780; сохранена полная страница. Владелец и вопросы вымышлены, HTTP-ответы API подменены; остальные разделы показывают состояние недоступного сервера. Синхронизация WebSocket не подключилась.

- `home-pult-1-pc-dark.png`, `home-pult-1-pc-light.png` — один вопрос с «Да» и «Нет», ПК, тёмная и светлая темы.
- `home-pult-1-phone-dark.png`, `home-pult-1-phone-light.png` — тот же вопрос, телефон, обе темы.
- `home-pult-3-phone-dark.png` — три вопроса: две карточки и «все 3 →».
- `home-pult-noopts-phone-dark.png` — вопрос без вариантов, кнопка «Открыть».
- `home-pult-empty-phone-dark.png` — вопросов нет, блок отсутствует.

Сверка с Figma, кадр `53:5907` (макет 390 px; снимки телефона 360 px):

- **Исправить:** в карточке появилась дополнительная строка с номером и временем, а подпись «≈ 9% недельного лимита» стала светлой вместо приглушённой. Карточка из-за дополнительной строки выше, чем на макете.
- **Норм:** горизонтальные поля и внутренние отступы карточки близки к макету; заголовок и кнопки выполнены в той же визуальной системе. При трёх вопросах «все 3 →» не налезает на заголовок.
- **Норм:** блок расположен перед остальными разделами Главной; в макете перед ним показано пояснение к нижней панели, это пояснение относится к макету.
- **Норм:** горизонтальной прокрутки при ширине 360 px в четырёх состояниях нет (ширина документа 360 px). Порядок и полное содержимое остальных разделов в макете не представлены.

При работе dev-сервера однажды появилось сообщение `ResizeObserver loop completed with undelivered notifications`; повторяемость и влияние не исследовались.
