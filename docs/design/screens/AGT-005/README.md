# Возможности на Главной (AGT-005): снимки по DESIGN_SYSTEM §0.5

Блок «Возможности» стоит на Главной сразу под сводкой от AI (D-734): до трёх олимпиад, хакатонов
и соревнований, которые отобрал агент. Снимки сделал Chromium (Playwright) на ПК 1440 px и телефоне
360 px в светлой и тёмной теме. **Сервер не запускался:** вход, синхронизация и ответы
`/api/v1/opportunities*` подменены моками из `apps/web/e2e/opportunities-mock.ts`; часы браузера
остановлены на 20 октября, поэтому год в датах не пишется. Снимок обрезан по низу блока — ниже
Главная не менялась.

Имя файла: `состояние-устройство-тема.png`.

| Состояние | Что видно |
|---|---|
| `cards` | Три карточки от агента: вид и этап, название, «Регистрация до …», даты, класс и предмет, место, «почему тебе», «Сайт организатора ↗», «Интересно» / «Не надо»; справа от заголовка — «отобрал агент» |
| `long` | Очень длинные название, этап, место и «почему тебе»: переносятся только между словами, ничего не обрезано и не выходит за карточку |
| `new` | Агент ещё не отобрал — ближайшие новые, справа от заголовка «без отбора агента», строки «почему тебе» нет |
| `empty` | «Агент пока ничего не нашёл» и кнопка «Обновить» (собрать из источников сейчас) |
| `error` | Список не загрузился: «Возможности сейчас недоступны» и «Повторить» (как у погоды и курсов — текстом, без тревоги) |
| `done` | После «Интересно»: «Дела поставлены: 3» и «Что сделал агент →» (лента с откатом в «Агенте») |

| `action-error` | «Интересно» не прошло: ошибка под кнопками, кнопки снова доступны |

## Чем проверено

| Пункт | Итог |
|---|---|
| Горизонтальная прокрутка на 360 и 1440 px (`scrollWidth`) во всех 32 снимках | нет |
| Ни один элемент блока не выходит за блок и за свою карточку, ничего не обрезано | 0 находок |
| Кнопки и ссылки в карточках — не ниже 44 px | да |
| Цвета — только токены (`grep -nE "#[0-9a-fA-F]{3,8}\b\|rgb\(" home.css`) | пусто |
| Отступы — из сетки §0.2 (4 · 8 · 12 · 14 · 16 · 24) | да |
| Появление, уход, смена вида карточки — `Presence`; что ниже блока — доезжает `useFlip`; только `transform`/`opacity` | да |
| `e2e/frames.spec.ts` (CPU ×4) | зелёный |

## Решил так, можно откатить

- **«Не надо» уходит на сервер через 5 секунд.** До этого «Вернуть» просто отменяет — серверу не
  нужен отдельный «вернуть». Ушёл с Главной раньше — запрос отправляется сразу; закрыл вкладку —
  не отправляется, карточка появится снова.
- **Даты источников — в их поясе:** Кодолимп — по Москве, Devpost — UTC (так их пишет разбор,
  `docs/engineering/OPPORTUNITIES.md`). Иначе в Челябинске «до 27 октября» стало бы «до 28-го».
  Codeforces и записи вручную — в поясе устройства, со временем.
- **Ошибка загрузки — текстом**, как у соседних виджетов; `Note` с тревогой — только для ошибок
  после нажатия («Интересно», «Не надо», «Обновить»).
- Блок стоит под «Пока было тихо…», если оно есть, — то есть всё равно под сводкой.
