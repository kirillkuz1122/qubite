# AGT-006b — место и дорога у дела (#138)

Решил так, можно откатить: в списках название дела открывает общее окно `Sheet`.
На доске оно открывается через меню карточки → «Место и дорога», чтобы сохранить
перетаскивание карточки. В окне редактируется необязательное место; сохранение
идёт обычной синхронизацией и работает без сети. Смена места сразу убирает старые
минуты на устройстве. Рассчитанное время видно в списках и на доске.

Перед первым запросом показывается пояснение про геолокацию. Разрешение запрашивает
браузер только после нажатия. При отказе показана подсказка «Откуда ехать».
Запросы Nominatim/OSRM выполняет сервер; браузер рисует только SVG по ответу.
Исходная точка и геометрия живут в памяти открытого окна, без localStorage,
IndexedDB, очереди синхронизации и кэша запросов. Закрытие окна отменяет запрос.
Ссылка Яндекса и ссылка на копирайт OSM открываются только по нажатию.

## Зависимость от серверной основы

В выданной рабочей копии нет AGT-006a, `docs/engineering/ROUTES.md` и решений
D-740/D-741. Контракт прочитан через GitHub из основы
[`task/AGT-006`](https://github.com/kirillkuz1122/qubite/tree/task/AGT-006):

- [`ROUTES.md`](https://github.com/kirillkuz1122/qubite/blob/task/AGT-006/docs/engineering/ROUTES.md);
- [`decisions/78.md`](https://github.com/kirillkuz1122/qubite/blob/task/AGT-006/docs/product/decisions/78.md);
- [`routes.rs`](https://github.com/kirillkuz1122/qubite/blob/task/AGT-006/crates/qubite-server/src/routes.rs).

Для работы нужен сервер AGT-006a. Его код и миграции в этой UI-задаче не переносились
и на Pi не применялись. `POST /api/v1/planner/tasks/{id}/route` получает
`{"from":{"lat":55.16,"lon":61.4}}`. Ответ — `minutes`, `meters`, `geometry`
(список объектов `{lat, lon}`), `to`, `place_text`, `provider`, `attribution`.
Клиент использует общий механизм cookie/CSRF. Перед расчётом он отправляет место
на сервер, а после расчёта забирает минуты через sync/pull.

Решил так, можно откатить: до повторной генерации OpenAPI контракт добавлен
отдельным типизированным дополнением `packages/api-client/src/planner-route.ts`.
Сгенерированные `schema.ts` и `openapi.json` вручную не менялись.

DESIGN_SYSTEM §0.5: токены, `Button size="sm"` в заголовке «Дорога», подписи «Вы» и
«Место» с обводкой поверх линии, на 360 px без горизонтальной прокрутки. Снимок
результата прокручен до ссылок «Открыть в Яндекс Картах» и «© OpenStreetMap».

В `apps/web/e2e/task-route.spec.ts` подготовлены сценарии со stub API и
подменённой геолокацией. При запуске CI они сохраняют сюда PNG окна места и
результата маршрута для 1440×900 и 360×780, в светлой и тёмной темах, отдельно
для каждого браузерного проекта. Те же PNG прикладываются к отчёту Playwright.
В сценарии проверяются ширина страницы и окна без горизонтальной прокрутки.

Приёмка владельцем пока не завершена; UI-задача не объявляется готовой до неё.
