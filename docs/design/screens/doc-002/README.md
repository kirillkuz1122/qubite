# DOC-002c — снимки документов

На Raspberry Pi снимки не создавались: задание #144 запрещает запуск браузера,
тестов и сборок на Pi. Визуальная проверка и приёмка владельца ещё нужны.

`apps/web/e2e/docs.spec.ts` подготовлен для CI: список и открытый документ,
1440×900 и 360×780, светлая и тёмная темы. Тест сохраняет PNG в эту папку и
прикладывает их к отчёту Playwright. Имена содержат браузер, экран, ширину и тему;
файлы появятся после запуска CI, затем их можно приложить к PR.
