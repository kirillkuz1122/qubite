# DOC-002 — снимки документов

Снимает `apps/web/e2e/docs.spec.ts` (Chromium): список и открытый документ,
1440×900 и 360×780, светлая и тёмная темы. Имена: браузер, экран, ширина, тема.
`editor-focus-360-*` — документ на телефоне, когда в нём пишут: панель блоков
видна только в этот момент и стоит над каплей (с клавиатурой — над ней).
Тема ставится через настройки вида до загрузки, снимок — после сборки заголовка из точек.
