# Календарь (CAL-002): проверка вёрстки после переделки по образцу Google Calendar

Снимки сделал Chromium (Playwright) на ПК 1440×900 и телефоне 360×780, в светлой и тёмной теме.
**Сервер не запускался:** вход и синхронизацию подменили моки из `apps/web/e2e` (`auth-mock`,
`sync-mock`), ответы `/api/calendar` и `/api/calendar/events/{id}` — по образцу настоящих.
Время зафиксировано: вторник, 3 ноября 2026, 10:20, пояс Asia/Yekaterinburg.

Имя файла: `вид-устройство-тема.png`, устройство — `pc` или `phone`.

| Вид | Что на снимке |
|---|---|
| `week-empty` | пустая неделя |
| `week` | неделя с записями: три одновременно (вт 10:00), три по 15 минут подряд (вт 14:00), длинное название и место (ср 12:00), «весь день» на три дня с длинным названием, дело на весь день, уроки |
| `day`, `month` | день и месяц с теми же записями |
| `quick` | короткая карточка после нажатия на пустое место (чт 15:00) |
| `quick-allday` | нажатие на пустое место строки «весь день» (ПК — пт, телефон — чт) |
| `form`, `form-end` | полная форма («Другие параметры»); она же, прокрученная до конца, повтор «По дням недели» |
| `edit`, `edit-end` | открытое событие с повтором; оно же внизу, открыто подтверждение «Удалить» |
| `drag` | протяжка по пустому месту 13:00 → 15:00 (кнопка мыши ещё нажата) |

**До правки** — часть тех же снимков в [`before/`](before/). Стиль, палитра, шрифты и компоненты
не менялись (D-806): правилась раскладка.

## Чем проверено

| Критерий | Итог |
|---|---|
| 1. На ПК неделя во всю ширину рабочей области, колонка ≥ 120 px, шкала не под Command | да: 1112 из 1112 px, колонка 153 px, зазор до Command 24 px |
| 2. Шапка на 360 px ≤ 120 px, «Сегодня»/стрелки/период/вид/«+» без наложений, зоны ≥ 44 px | да: 110 px; автопроверка наложений и размеров — 0 находок |
| 3. Нет горизонтальной прокрутки на 360 px | да, во всех 44 снимках (`scrollWidth = clientWidth`) |
| 4. «Сохранить»/«Другие параметры»/«Отмена»/«Удалить» закреплены внизу листа и не перекрывают поля | да: панель внизу листа на ПК и телефоне, поля прокручиваются над ней с отступом 24 px |
| 5. Нет кнопок «Создать» в «весь день» и в часах; нажатие на пустое место открывает карточку с нужным временем | да: 0 кнопок «Создать»; чт 15:00 → карточка 05.11 15:00–16:00; «весь день» пт → карточка «Весь день» 06.11 |
| 6. Только токены `--q-*`, анимации — `transform`/`opacity` | да: в изменениях ветки нет `#hex`, `rgb()`, `transition`, `@keyframes`, `filter` |
| 7. Ошибок в консоли нет | да: 0 ошибок и предупреждений (`console`, `pageerror`) во всех 44 снимках |

Автопроверка в каждом снимке (как в CAL-001): текст не выходит за свой элемент и не срезан краем
без намеренного многоточия, кнопки не срезаны краем, все кнопки ≥ 44×44 px, кнопки шапки и
нижней панели листа не наезжают друг на друга, нет горизонтальной прокрутки страницы и внутри
календаря. Она находок не дала ни до, ни после: срезанную рамку поля нашли глазами по снимкам,
шапку 130 px — по замеру. Поэтому в отчёт добавлены замеры (шапка, колонка, низ шкалы, нижняя
панель листа) и значения полей карточки после нажатия.

Также: `pnpm lint`, `typecheck`, `test`, `build`, `prettier --check` — зелёные.

## Осталось (решение владельца или отдельная задача)

1. **Телефон по D-802:** вид должен выбираться из меню по нажатию на название периода, а «+» —
   плавающей кнопкой над Command. Сейчас — `Segmented` и «+» во второй строке шапки (шапка и так
   110 px). Плавающая кнопка — новый общий приём в `packages/ui` (D-806), отдельная задача.
2. **Короткая карточка:** «Название» не получает фокус сразу — фокус у окна, печатать можно только
   после нажатия на поле. Причина в `Sheet` (`packages/ui`): ищет атрибут `autofocus`, а React его не
   ставит и сам фокусирует поле раньше, чем `Sheet` забирает фокус себе. Там же ломается возврат
   фокуса после закрытия. Исправлять в `Sheet` с тестами, не в календаре.
3. **Ноутбук 1024 px:** неделя (7 × 120 px) не помещается и прокручивается вбок; Google в таком окне
   сужает колонки. Оставить ≥ 120 px (D-800) или сузить до ~90, как на телефоне?
4. **Пояс на 360 px** сокращается до «Asia/Yekaterin…» (полностью — в подсказке; на 375 px и шире
   помещается).
5. **Месяц** — только точки, без названий (Google пишет названия в клетках).
6. Даты и время в полях — формат браузера проверки (en-US: `11/05/2026`, `03:00 PM`), не дефект.
