# DOC-003d1: частичная проверка упоминаний и обратных ссылок

Chromium с поддельным API, 1440×900 и 360×780, светлая и тёмная темы. Включён `prefers-reduced-motion: reduce`. Клавиатура телефона физически не эмулировалась. Имена кадров содержат состояние, ширину и тему.

| Состояние | ПК | 360 | Найденное |
|---|---|---|---|
| Меню @, документы, выбранная строка | `at-menu-1440-*` | `at-menu-360-*` | Первая строка 44 px высотой; остальные строки не измерены. |
| Ничего не найдено | `at-empty-1440-*` | `at-empty-360-*` | Сообщение видно. |
| Обычный и удалённый чип | `chip-1440-*`, `chip-deleted-1440-*` | `chip-360-*`, `chip-deleted-360-*` | Удалённая цель показана серым «Удалено»; контраст инструментально не измерен. |
| Выделенный чип | `chip-selected-1440-*` | `chip-selected-360-*` | Первоначальный проход подтвердил выделение и удаление двумя Backspace во всех четырёх вариантах; повторный проход после изменения состояния цели дал неоднозначный результат. |
| Ссылаются сюда, шесть ссылок | `backlinks-six-1440-*` | `backlinks-six-360-*` | На кадре телефона нижняя панель перекрывает часть списка. Нужно отдельно проверить прокруткой доступность последней строки и «Ещё 1». |
| Дела и проекты в меню, без сети | — | — | Не проверено. |
| Длинное название, позиции чипа и пункт списка | — | — | Не проверено. |
| «Вернуть?» потерянного чипа | — | — | Не проверено. |
| 0, 1, 3 ссылки; дело и проект; стрелки | — | — | Не проверено. |

Tab выбрал найденный объект, фокус оказался в редакторе во всех четырёх сочетаниях. Горизонтальной прокрутки страницы в момент открытого меню не было (ширина страницы равна ширине окна). Esc закрывает меню с задержкой анимации: мгновенное чтение видимости после нажатия не всегда отражает конечное состояние; устойчивость и Shift+Tab не проверены. Reduced motion был включён, но движение отдельно не оценивалось. Зоны касания других элементов, фактическая мобильная клавиатура и её перекрытие требуют отдельной проверки.

В консоли разработки при показе обратных ссылок React предупреждает о передаче `key` через spread в `BacklinksList`. Воспроизведение: открыть документ с обратными ссылками с моковым API и посмотреть консоль dev-сервера. Запрос `/api/platform/status` ожидаемо не прошёл: настоящий API для проверки намеренно отключён.

Кадры и наблюдения не заменяют приёмку владельцем на телефоне. Код приложения и тесты не менялись; сборки и тесты на Pi не запускались.
