## Замечания Terra (PR #193)

1. **Капля закрывает список на 360 px — не подтвердилось.** Кадр Terra снят без
   прокрутки. У `.main-in` на телефоне снизу 150 px, как во всех экранах; в конце
   прокрутки низ последней строки — 630 px, верх капли — 708 px (+ safe-area до
   34 px всё равно оставляет зазор). В листе дела капли нет (лист выше неё).
2. **Предупреждение React о `key` — исправлено.** `useBacklinks` возвращал всё
   своё состояние вместе с полями `key` и `session`, а `Backlinks` раскладывал его
   в пропсы. Теперь хук отдаёт только `backlinks` и `message`; e2e следит, чтобы
   предупреждения не было.
3. **Неполная проверка — досняты все варианты** (таблица выше).

## Клавиатура, касания, офлайн

- Меню `@`: ↑/↓, Enter, Tab выбирают; клик мышью и тап по пункту — тоже; после
  выбора фокус в тексте, набор продолжается. Esc закрывает, набранное остаётся.
- **Исправлено:** из текста нельзя было уйти клавиатурой — Tab менял отступ, и
  «Ссылаются сюда» были недостижимы. Теперь **Esc, затем Tab/Shift+Tab** выводит
  фокус (как в редакторах кода); без Esc Tab — отступ, как раньше. Чипы больше не
  остановки Tab (раньше Tab попадал на первый чип и перескакивал остальные).
- Панель: ↑/↓ по кругу, Enter и пробел открывают, Ctrl/⌘ — новая вкладка.
- **Исправлено (офлайн):** тап по чипу перезагружал страницу (`location.assign`);
  без сети это не открыло бы цель. Теперь переход внутри приложения, как у панели.
- **Исправлено (телефон):** блок прятался при наборе по событию `input`, которого
  в Chromium нет (Lexical вставляет текст сам) — тест `набор и офлайн 360px` падал
  в Chromium. Теперь по `beforeinput`.
- Нет гориз. прокрутки на 360 px во всех состояниях; цвета — только токены;
  анимации — `Presence`/`useSlide`/пружина (transform и opacity).

## Что решить владельцу

1. **Обводки в светлой теме:** `--q-orange` (фокус везде) и `--q-sky` (выделенный
   чип) на светлом фоне — 2,1–2,3:1, ниже 3:1 для рамок. Это токены всей системы,
   не менял. Нужна ли более тёмная обводка фокуса в светлой теме?
2. **Чип высотой 44 px** делает строку с чипом выше соседних (≈ 29 → 44 px).
   Это ради зоны касания; посмотреть на телефоне, не мешает ли чтению.
3. **Esc, затем Tab** — подходит ли такой выход из текста (решил так, можно откатить).
4. Экранная клавиатура телефона не эмулировалась: меню над клавиатурой — проверить на Redmi.
5. Кадры PR #193 (Terra) лежат в той же папке с теми же именами (`at-menu-*`,
   `at-empty-*`, `chip-*`) — после слияния DOC-003c закрыть #193 или оставить из
   него только `REPORT.md`.
6. Не трогал (DOC-002): возвращённый блок встаёт после пустой строки и с пробелом
   в начале; документ без названия в списке Docs показывается без заголовка.
