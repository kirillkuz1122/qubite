# Дизайн-система Qubite v2 — «Частицы»

> **Версия 2 от 14.11.2026 (DS-012, [D-860…D-872](../product/decisions/89.md)).** Стиль прежний: всё из точек, тёплый чёрный и «тёплая бумага», Tiny5 точками, Fira Code, оранжевая точка-действие ([D-154…D-167](../product/DECISIONS.md)). Новое в v2 — полные макеты в Figma, шкала текста и отступов, цвета для текста, состояния каждого элемента, навигация телефона с подписями.
>
> **Макеты:** [Figma — Qubite Design System](https://www.figma.com/design/UZ5s8bNDVUfqK2yy80DAWR). Снимки для GitHub — [screens/DS-012/](screens/DS-012/). Что не так на сайте сейчас — [проверка дизайна](../reports/design-audit-2026-11-13.md).
>
> **Как читать.** Код — `packages/ui` (компоненты, токены `--q-*`), `packages/motion` (одна физика), витрина `/design`. Всё из этого документа перенесено в код задачей DS-013 ([D-901…D-915](../product/decisions/94.md)); что не вошло — в §10.

## 0. Правила стиля — обязательны для каждого изменения UI

> Владелец 21.10.2026: «элементы выбиваются из стиля, неправильные отступы, цвета, выравнивание… записать правила, чтобы агенты больше так не делали» ([D-436](../product/DECISIONS.md)). Нарушение правила = UI-задача не готова.

### 0.1. Только общие компоненты `packages/ui`

| Нужно | Бери | Нельзя |
|---|---|---|
| Кнопка действия | `Button`: `variant="fill"` — главная, одна на экран или окно; обычная — рамка; тихая — без рамки (`variant="quiet"`), для вторых действий. `size="sm"` — в строке | свой `<button class="…">` с рамкой и заливкой |
| Кнопка-значок | `IconButton`: зона 44×44, подпись `aria-label` | значок без зоны нажатия |
| Вкладки, виды, фильтры | `Segmented` (`variant="chips"` — фильтры с числами). Не помещается в 360 px — сам переходит в ряды | свой ряд кнопок; горизонтальная прокрутка страницы |
| Смена вкладки / вида | `Swap` вокруг содержимого | `{tab === 'a' && …}` без перехода |
| Окно, форма, подтверждение | `Sheet` (ПК — по центру, телефон — нижний лист; Escape, нажатие мимо, фокус внутри) | форма, раскрытая внутри страницы; свой `position: fixed` |
| Блок появляется / исчезает | `Presence` (соседи — `useFlip`), строки списка — `useLeaving` | `{open && <div>}` рывком |
| Выделение строки / пункта | `useSlide` (подложка перетекает) | `background` сменой класса |
| Значок | `DotIcon` — только из точек; новый — в `icons.tsx` (сетка 20×20, 4–13 точек) | эмодзи и символы (⚙, ✕, 🔔), контурные SVG |
| Крупный заголовок | `DotText`; заголовок секции — `SecHead` | обычный жирный текст вместо заголовка |
| Поле, пароль, флажок, переключатель, ползунок, выбор | `Field` (`reveal` — глаз), `Check`, `Switch`, `Range`, `Choice` | `<input>` без `Field` |
| Сообщение, ошибка | `Note` (`tone`), под полем — `error` у `Field` | красный текст своим стилем |
| Пустой раздел | `EmptyState`: помощник, одна фраза, одно действие | серая строка «ничего нет» |
| Подтверждение с откатом | `Toast` (`useToast().show(текст, { undo })`) | `alert`, баннер посреди страницы |

Точка в кнопке: у главной и обычной есть всегда, у тихой — никогда. Знак «+» в текст кнопки не пишем.

### 0.2. Сетка отступов и раскладка

- Шаг **4 px**. Шкала: **4 · 8 · 12 · 16 · 24 · 32 · 40 · 64**. Других чисел не придумывать (старые 14, 18 и 26 заменены в DS-013). Поле экрана телефона — 16 px.
- Поля экрана: телефон **16 px**, ПК **40 px**; колонка чтения — 680 px по центру. Широкие экраны (Календарь, Docs) — на всю ширину.
- Секция: `SecHead` — сверху 24 px, снизу 12 px. **Действие секции — справа от заголовка**, по его нижнему краю.
- Карточка (`.panel`): внутри 16 px, плотная — 12 px; между карточками 12 px.
- Зона нажатия — не меньше **44×44 px**.
- Под контентом запас: ПК **140 px** (строка Command), телефон **104 px** (нижняя панель). Command и панель не закрывают последние строки.
- Экран 360 px — **без горизонтальной прокрутки**. В сетках `minmax(0, 1fr)`, у flex-детей с текстом `min-width: 0`. Пользовательский текст (названия, мысли, ссылки) — `overflow-wrap: anywhere`.
- На телефоне срок и подпись строки уходят **под** название, а не сжимают его.
- Всплывающее (колокольчик, меню, подсказки) не закрывает шапку и строку Command.

### 0.3. Цвета — только токены `--q-*`

Никаких `#hex` и `rgb()` в CSS приложения — только переменные из `packages/ui/src/tokens.css`. Значения обеих тем — §1.1.

| Токен | Роль |
|---|---|
| `--q-bg`, `--q-bg-2`, `--q-panel`, `--q-panel-2` | фон, фон глубже, карточка, вложенная поверхность / наведение |
| `--q-ink`, `--q-mute`, `--q-dim` | основной текст, вторичный, подписи |
| `--q-line`, `--q-line-2`, `--q-faint` | разделители и рамки карточек; рамка кнопки и поля; неактивные точки |
| `--q-orange` | действие и акцент: одна главная кнопка, «новое», точка-маркер |
| `--q-sky`, `--q-yellow`, `--q-green`, `--q-red`, `--q-peach` | выбор и событие, мысль, успех, ошибка, помощники — по смыслу |
| `--q-orange-ink`, `--q-sky-ink`, `--q-yellow-ink`, `--q-green-ink`, `--q-red-ink` | те же роли **для текста**: в светлой теме темнее |
| `--q-orange-hover` | главная кнопка под курсором |
| `--q-on-accent`, `--q-veil`, `--q-shadow` | текст на оранжевом, затемнение под окном, тень |

- Яркий цвет — на точках и заливках. Цветной **текст** — только токенами `-ink`.
- Ошибка — `--q-red` (рамка) и `--q-red-ink` (текст), всегда с точкой и словами. Персиковый — цвет помощников, не ошибки.
- Ссылки-действия («все →», «Скачать .md») — без подчёркивания: `--q-mute`, под курсором `--q-ink`. Подчёркивание — только внутри абзаца.

### 0.4. Анимации

- Двигаем **только `transform` и `opacity`**, пружинами из `@qubite/motion` через компоненты §0.1 (одна физика, D-142). Ничего не появляется и не исчезает рывком.
- Что чем: раздел — `AppShell`; вкладка — `Swap`; окно — `Sheet`; блок — `Presence`; выделение — `useSlide` / `useFlow`; значок — `DotIcon`; нажатие — `Button` / `usePress`. Полная таблица — §3.
- CSS-переходы — только цвет и `opacity` при наведении, до 0,2 с. Свои `@keyframes` — нельзя, кроме существующих коротких (`talk-in`, `q-found`, `q-blink`).
- Без `filter`, `backdrop-filter`, анимированных теней, `width/height/top/left` в анимации.
- Тест кадров `e2e/frames.spec.ts` (CPU ×4) — зелёный на CI. Порог не менять.

### 0.5. Чек-лист перед коммитом UI (обязателен)

1. Скриншоты **ПК 1440×900 и телефон 360×780** всех затронутых экранов: `node scripts/ui-screens.mjs docs/design/screens/<задача>` (нужны `just dev` и owner; в облаке — `QUBITE_CHROMIUM=/opt/pw-browsers/chromium`). Посмотреть глазами и положить в задачу.
2. На 360 px нет горизонтальной прокрутки — **с настоящими данными**: длинное название, ссылка без пробелов, три строки текста. Ничего не обрезано и не наезжает.
3. Каждое переключение — с анимацией из §0.4; только `transform` / `opacity`.
4. Цвета — только токены (`grep -nE "#[0-9a-f]{3,8}|rgb" *.css` в своих файлах пуст). Обе темы; цветной текст в светлой читается.
5. Нет самодельных кнопок, вкладок, окон, значков-символов — только §0.1. Главная кнопка на экране одна.
6. Отступы — из §0.2; текст — из шкалы §1.2, фразы не мельче 13 px.
7. У нового элемента есть наведение, фокус с клавиатуры и недоступное состояние (§2).
8. Экран сверен с макетом в Figma; расхождение записано в задаче.
9. `just check` и `just e2e` зелёные; в STATUS — что посмотреть владельцу.

### 1.3. Форма

- Скругление следует за формой точки (`--q-round`, по умолчанию 0,5). Шкала: **4** — флажок, клавиша, метка; **8** — малая кнопка, пункт меню; **10** — кнопка, карточка; **12** — поле, окно, вкладки; **14** — Command, нижняя панель.
- Точка — квадрат со скруглением 25% стороны. Размеры: 4 — кольцо дела; 6 — ход выполнения; 8 — маркер строки; 10 — отметка флажка; 12 — «сделано».
- Тень — только у того, что плавает над страницей: Command, нижняя панель, меню, окно, toast. Тень не анимируется.

Под курсором меняется только цвет, за 0,15 с. Размер и положение не меняются.

|---|---|---|---|---|

| Кнопка обычная | рамка `line-2`, текст `ink` | заливка `panel-2` | то же; рамка `mute` | — |
| Кнопка тихая | текст `mute`, без рамки | текст `ink` | заливка `panel-2` | — |
| Кнопка-значок | значок `mute` | значок `ink` (с рамкой — заливка `panel-2`) | сжатие до 0,86 | — |
| Ссылка-действие | `mute` | `ink` | — | — |

| Пункт меню ПК | текст и значок `mute` | текст и значок `ink` | сжатие | подложка `panel` с рамкой `line`, число — `orange-ink` |

| Поле | рамка `line-2` | — | — | фокус: рамка `orange` |
| Переключатель | дорожка `panel-2`, ручка `mute` | — | ручка тянется | дорожка `orange`, ручка `on-accent` |
| Карточка-ссылка | рамка `line` | рамка `line-2` | сжатие до 0,98 | — |

Общие состояния:

- **Фокус с клавиатуры** — контур 2 px `orange` с отступом 3 px (`:focus-visible`). Порядок Tab — сверху вниз, слева направо. В окне фокус не выходит наружу.
- **Недоступно** — прозрачность 45%, курсор «нельзя», прежняя заливка, без наведения и нажатия ([D-671](../product/DECISIONS.md)).
- **Идёт действие** — в кнопке вместо точки три точки `Loader`, кнопка недоступна, текст не меняется. На странице — три точки и серые строки на месте будущего текста, без спиннера.
- **Успех** — главная кнопка на секунду зелёная «Сохранено»; действие с последствиями — `Toast` с «Откатить» на 5 секунд.
- **Ошибка** — точка, красная рамка и текст простыми словами: что случилось и что делать. Поле качается «нет».
- **Отмена жеста** — увёл палец дальше 48 px или нажал Escape: элемент возвращается, действие не срабатывает.
- **Пусто** — `EmptyState`: помощник раздела, одна фраза, одно действие.
- **Нет сети** — `Note` «Нет сети. Всё сохраняется на устройстве и отправится само»; у несохранённого — «ждёт отправки».

## 3. Движение

Главное требование владельца: интерфейс **ощущается живым**. Движение задаётся пружиной, а не таймером; прерванная анимация продолжается с той же точки и скорости ([D-142](../product/DECISIONS.md)). Жёсткость у всех 220, меняются масса и вязкость. Владелец выбрал характер «Пружинистый» ([D-182](../product/DECISIONS.md), `packages/ui/src/feel.ts`):

| Элемент | Масса | Вязкость |
|---|---|---|
| Кнопка | 0,7 | 11 |
| Подложка выбора | 0,9 | 13 |
| Переключатель | 0,8 | 12 |
| Ползунок | 0,6 | 10 |

| Случай | Приём | Как выглядит |
|---|---|---|
| Смена раздела | `AppShell` | заголовок из точек рассыпается и собирается в новое слово |
| Смена вкладки, вида | `Swap` | старое уходит и гаснет, новое проявляется |
| Окно | `Sheet` | ПК — вырастает из точки нажатия; телефон — снизу, тянется, закрывается свайпом |
| Блок появился, исчез | `Presence` + `useFlip` | блок проявляется, соседи раздвигаются |
| Строка ушла из списка | `useLeaving` | строка сжимается и гаснет |
| Выделение | `useSlide`, `useFlow` | подложка перетекает через промежуточные пункты |
| Смена значка | `DotIcon` | те же точки перестраиваются |
| Нажатие | `Button`, `usePress` | сжатие, отскок |
| Дело сделано | `RingCheck` | 12 точек слетаются в одну зелёную |
| Запись через Command | `fly` | точка летит в раздел, куда легла запись |
| Подсказка Command | `CommandSuggest` | карточка вырастает вверх из строки |
| Меню создания | `PlusMenu` | «+» превращается в меню |
| Подтверждение | `Toast` | поднимается над Command, через 5 с гаснет |

«Меньше движения» и `prefers-reduced-motion`: пружины заменяются мгновенной сменой с проявлением. Облегчённый режим: без фоновой сетки точек и помощников.

## 5. Раскладка

- **ПК:** боковая панель 248 px (логотип, разделы, группа «Модули», внизу аккаунт и колокольчик); колонка 680 px по центру; строка Command 660×58 внизу по центру.
- **Телефон:** заголовок раздела и колокольчик сверху, помощник справа; нижняя панель 64 px: **Главная, Сегодня, Planner, Ещё** с подписями 10 px и оранжевая кнопка Command справа ([D-866](../product/decisions/89.md); «Входящие» — в «Ещё» по [D-945](../product/decisions/95.md)). «Ещё» открывает лист плитками: Входящие, Календарь, Агент, Docs, Английский, Настройки и будущие модули.
- **Прокрутка:** у страницы полосы нет (точки у края, `EdgeScroll`); внутренние блоки — тонкая полоса из токенов `line-2` / `dim`, без стрелок ([D-912](../product/decisions/94.md)).
- **404:** своя страница по макету «Экраны → 404» ([D-911](../product/decisions/94.md)).
- **Заголовок страницы:** `DotText`, под ним строка-подзаголовок 13 px, справа помощник раздела (Прото — дела, Элик — мысли, Нейт — знания, Фоти — личное).
- **Главная:** сводка от AI → дела → входящие → сроки → одна карточка возможностей → погода и курсы.

## 6. Как собрать новую страницу

1. Возьми похожий экран со страницы «Экраны» или «Новые модули» в Figma.
2. Каркас: заголовок страницы → вкладки (`Segmented`), если есть виды → секции с `SecHead` → строки или карточки.
3. Одна главная кнопка. Остальные действия — обычные и тихие.
4. Проверь на 360 px: длинные названия, срок под названием, без прокрутки вбок.
5. Пройди чек-лист §0.5.

Надписи точками в Figma собирает библиотека на странице `_lib` (скрытые слои `core`, `part:ui`, `data:*`, `registry` — не удалять). Агент загружает её так: `const core = await figma.getNodeByIdAsync('3:3'); const Q = await (new Function('return ' + core.characters))()(figma, core);` и вызывает `Q.screen(page, название, активный раздел, () => [ … ])` — экран получается сразу на ПК и телефоне в двух темах.

## 7. Значки

Сетка 20×20, 4–13 точек, радиус точки 1,0–2,7, цвет — от текста. 63 значка — все в `icons.tsx` (координаты сняты со страницы «Значки» в Figma; тест проверяет число и сетку): разделы, закрыть, стрелки, человек, замок, фильтр, список, доска, скачать, проект, место, откатить, значки модулей.

## 8. Доступность

Контраст текста AA в обеих темах, видимый фокус, работа с клавиатуры, подписи у значков-кнопок, `aria-current` / `aria-pressed` у выделений, «меньше движения», масштаб до 200% без поломок. Ошибка и статус — не только цветом.

## 9. Производительность

1. Анимации — только `transform` и `opacity`; `will-change` — только на время анимации.
2. Физика считается в одном цикле `requestAnimationFrame`; всё успокоилось — цикл остановлен.
3. Без `filter: blur`, `backdrop-filter`, анимированных градиентов и теней.
4. Раскладку читаем до начала анимации, не на каждом кадре.
5. Бюджет: 60 к/с при замедлении CPU ×4; финальная приёмка — владелец на своём телефоне.
6. Холсты с точками — только через `DotEngine`; за экраном не рисуют, стоящие точки не перерисовываются ([D-541, D-542](../product/DECISIONS.md)).
