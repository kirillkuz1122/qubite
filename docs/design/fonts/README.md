# Шрифты для макетов

Локальные файлы с кириллицей (внешние CDN нельзя). Каждый шрифт разбит на два файла — кириллица и латиница; в CSS их подключают двумя `@font-face` с `unicode-range`, как в страницах `explorations/`.

| Файлы | Шрифт | Где используется | Лицензия |
|---|---|---|---|
| `SourceSerif4-*` | Source Serif 4 (вариативный, с оптическим размером) | заголовки «Ядра» | SIL OFL 1.1 |
| `Onest-*` | Onest | текст «Ядра», витрина | SIL OFL 1.1 |
| `Rubik-*` | Rubik | «Желе» | SIL OFL 1.1 |
| `GolosText-*` | Golos Text | текст «Частиц» и «Пикселя» | SIL OFL 1.1 |
| `Tiny5-*` | Tiny5 (пиксельный) | заголовки «Частиц» и «Пикселя» | SIL OFL 1.1 |

Взяты из пакетов `@fontsource` (уже были в `node_modules` и в сборке старой лаборатории `assets/design-lab`).
