# Частицы — всё из точек

> **Основное направление (D-154).** Точка — квадрат со скруглением 50%, размер 95% (D-155). Шрифт текста — **Fira Code** (D-160). Две темы: тёмная (основная) и светлая — тёплая бумага (D-163).

**Идея:** мысль — это точка. Из точек складываются дела, дни и сами помощники.

**Почему подходит Qubite**
- Буквально «Атом Qubite» ([D-131](../../../product/DECISIONS.md)): помощники — частицы, собранные из частиц.
- Точечный стиль Nothing и пиксельный маскот Claude, но точки скруглённые — у помощников нет острых углов.
- Тёмный экран — для вечерней учёбы, на OLED-экране бережёт батарею. Днём — светлая тема.

## Лендинг: что оживает при прокрутке

- **Первый экран.** Проведи по заголовку — точки разлетятся и вернутся. Напиши мысль и нажми Enter: она рассыплется на точки и улетит к Элику. При прокрутке заголовок рассыпается вверх.
- **История «Как устроено»** — сцена прилипает к экрану, а одни и те же точки перестраиваются волной слева направо:
  1. облако мыслей;
  2. строки «Входящих» — выходит Элик;
  3. неделя по часам — выходит Прото;
  4. страница конспекта с параболой «от руки» — выходит Нейт;
  5. сердце — Фоти закрывает глаза;
  6. атом: ядро и орбиты, все четверо вокруг.

  Полоска-индикатор перетекает к текущему шагу.
- **Command.** Строка сама понимает, что ты написал: дело (со сроком), мысль, поиск или запись в дневник. Карточка под строкой меняется, нужный помощник выпрыгивает, остальные прячутся.
- **Для учёбы.** Рукописная страница Ink дописывается точками по ходу прокрутки, потом выезжают карточки для повторения.
- **По-честному и финал.** Значки собираются из точек, когда появляются на экране; в конце «Начни с одной точки» и помощники прыгают.
- Кнопка с половинкой точки в шапке меняет тему **волной точек** от кнопки.

## Приложение: движение

| Что | Как ведёт себя |
|---|---|
| Переход между разделами | Заголовок из точек **перестраивается в новое слово** теми же точками; помощник раздела выпрыгивает, прежний уходит вниз; экран сдвигается в сторону перехода |
| Нижняя строка на телефоне | Разделы и кнопка Command — две «капли». Нажми на Command: разделы стягиваются в точку, строка вытекает на их место. Нажми на точку — всё обратно |
| Подсветка выбранного | Перетекает: ведущий край убегает вперёд, хвост догоняет (разделы, фильтры, «Неделя / Доска», дни недели, тема) |
| «+» → меню | Кнопка раскрывается в меню, пункты выезжают по очереди, «+» поворачивается в «×» |
| Сохранение | Пишешь в Command — над строкой появляется карточка «Дело / Мысль / Поиск». После Enter карточка схлопывается в точку, и точка **долетает до своего раздела** |
| Разбор «Входящих» | «В дела» — строка схлопывается, точка летит в Planner, соседние строки плавно подтягиваются |
| Документ | Строка в Docs **раскрывается в страницу**; «Docs» сверху или Esc — обратно в строку |
| Дело сделано | Кольцо из 12 точек стягивается в одну зелёную |
| Переключатели | Точка-ручка вытягивается в сторону движения и собирается на месте |

**Настройки** (раздел «Настройки» в приложении, на лендинге — кнопка «Настроить»): тема «Тёмная / Светлая / Авто», форма точки (квадрат ↔ круг) и размер точки. Выбор общий для лендинга и приложения.

**Физика.** Одна на всё: пружина с жёсткостью 220 и вязкостью 20, меняется только масса. Двигаются только `transform` и `opacity`. Холсты за экраном не считаются.

**Шрифты.** Tiny5 — крупные надписи, разложенные в точки; Fira Code (моноширинный) — весь текст.

**Минусы.** Мелкий точечный текст читается хуже — только для заголовков и цифр. Жёлтый на светлой бумаге бледнее, поэтому в светлой теме цвета помощников чуть глубже.

Снимки — в [screens/](screens/): `landing-*` (лендинг), `today-*` и `app-*` (приложение), `*-light-*` (светлая тема).
