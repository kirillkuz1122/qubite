# Референсы для дизайна

Владелец выбирает, что нравится **по ощущению**, и отмечает, что именно (как переключаются вкладки, шрифт, анимация, персонаж). Результат записывается в таблицу «Выбор владельца». Главный эталон уже выбран — **Claude** ([D-141](../product/DECISIONS.md)).

## Выбор владельца

| Референс | Что нравится | Куда применяем |
|---|---|---|
| Claude | Простота, пиксельный маскот и его анимации | Общее ощущение, помощники |
| **Apple Liquid Glass** — главный эталон движения | «Живой» интерфейс со своей идеологией: переливы, перетекание форм, анимации | Движение и материал (D-145) |
| Nothing | Стиль бренда (точки, пиксели) — не анимации | Вариант стиля «Пиксель» в лаборатории |
| Family | Первый экран: живая композиция из персонажей и предметов ([скриншот](references/family-hero.png)) | Лендинг: композиция с помощниками (D-148) |
| Клеймофизм | Надутые мягкие игрушечные формы — «понравилось бы» | Кандидат в направления |
| ArtCraft (getartcraft.com) | Общий вид приложения | Посмотреть на шаге 0 |
| Сайты, оживающие при прокрутке | Элементы появляются и меняются по мере прокрутки | Лендинг — по максимуму, приложение — сдержанно (D-147) |
