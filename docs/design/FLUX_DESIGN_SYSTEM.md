## Материал и движение

- Непрозрачный пигмент, тёплый фон, читаемый контур, скруглённые формы. Мягкость означает непрерывную геометрию и свет, а не blur/стеклянную подложку.
- Ограниченное перетягивание кнопок, ползунок с точным значением, drag switch, текучее выделение, раскрывающееся меню и native dialog. Drag/cancel не запускают click или native submit; keyboard остаётся доступным.
- На нажатие и на перетягивание selection реагирует одним языком: промежуточные координаты/размер/направление, smoothstep 3t²−2t³. Длительность 250–900 мс, исходно 520 мс. При быстром новом выборе начинает из текущего положения. Двухмерная навигация на телефоне движется и по вертикали.
- Наблюдатель размеров не пересоздаётся при выборе; первое уведомление не прерывает анимацию. Размер активного текста не меняет геометрию группы. После resize перетекание продолжается.
- Один requestAnimationFrame scheduler для всех **активных** физических controls; в покое работы нет. Spring интегрируется шагами не более 1/120 с с ограничением временного разрыва; записи округляются ниже визуальной точности и выполняются только для изменившихся переменных. Визуальный snapshot перехода создаётся только при смене сцены, а не при каждом вводе. Старый декоративный слой заморожен и inert.
- Лёгкий рендеринг автоматически включается на `pointer:coarse`, доступен вручную. Края/градиент остаются постоянными, перемещение/растяжение сохраняются. `will-change` применяется только пока control движется. Нет blur/WebGPU/библиотеки physics/постоянного JS render loop.
- Податливость 0–100; quiet/system reduced motion/0 отключают движение. Это технические меры, **не доказательство 60 FPS на физическом планшете**. Emulator touch и CPU slowdown не заменяют отзыв владельца на слабом телефоне/Safari.

Каждая схема имеет светлую и тёмную тему с отдельными текстовыми/фоновыми токенами. Headings: **Onest, Golos Text, Rubik, Manrope, Unbounded**. Body: **Onest, Golos Text, Rubik, Manrope, Lora**. Пять независимых вариантов в каждом списке; 25 сочетаний. Initial Onest/Golos Text был инженерным стартом итерации03. **13.10.2026 владелец выбрал Unbounded/Manrope; это новые defaults итерации04.** Unbounded намеренно экспрессивный display; Lora — вариант для чтения. Кириллица и латиница self-hosted WOFF2, `font-display:swap`, только выбранные/видимые семьи скачиваются браузером. Экран сравнения шрифтов закономерно использует все демонстрируемые семьи. OFL лицензии включены в public/licenses.

Источники: [Onest](https://fontsource.org/fonts/onest/about), [Golos Text](https://fontsource.org/fonts/golos-text/about), [Unbounded](https://fontsource.org/fonts/unbounded/about), [Rubik](https://fontsource.org/fonts/rubik/about). Метаданные/лицензии проверены в установленных Fontsource packages, версии зафиксированы lockfile. Шрифты не заменяются латинским шрифтом с неизвестной кириллицей. Настройки демо in-memory, без cookies/localStorage/backend; saved preferences — отдельная UI-002.

## Помощники и общение

Геометрическая основа сохранена, формы округлены, добавлены брови/небольшие предметные детали. Луми — тёплый круг, Кип — собранная тёмная форма, Пип — любопытная синяя вертикаль, Сэйдж — спокойный оливковый наблюдатель с очками и блокнотом. Прототип имён/персон не равен финальному брендингу. Отдельный слой позы поверх непрерывного idle, взгляд следит за mouse/touch через общий источник pointer, без React render на каждый move; offscreen idle paused. Восемь событий: пауза, начало/focus, успех, ошибка, собственный промах, слушание, размышление, отдых. Реплики сценарные, модели не вызываются.

Три режима демонстрации: тихий знак/короткое предложение, contextual speech bubble, диалог по запросу. У каждого есть область/имя, dismiss, короткий текст; на телефоне speech и character занимают своё место, не перекрывают друг друга. Автоматические hints в примере интерфейса занимают обычный поток страницы, доступны закрытие/10 секунд/hints off. Никакого focus stealing. Реальная политика инициативы/cooldown/context/sensitive data/grants/budget остаётся PET-001..003 по [контракту Milo](MILO_MATERIAL_AND_COMPANIONS.md).

### Дополнение владельца: появление из края (13.10.2026)

**Подтверждён принцип, точные места/условия отложены до разработки экранов.** Нужны разные сценарии присутствия, а не один постоянно стоящий персонаж:

| Сценарий | Видимость/появление | Уход/взаимодействие |
|---|---|---|
| Скрыт | без фигуры; маленькая вкладка только если выбран такой режим | раскрывается по запросу, не оставляет невидимый hit target |
| Выглядывает | глаза/часть силуэта мягко выходят из края безопасной области | отступает после паузы, может показать короткую подсказку |
| Пришёл к действию | появляется рядом с релевантным input/задачей | сохраняет clear area кнопок/клавиатуры, следует placement policy |
| Напомнил о себе | малый сигнал после конкретного разрешённого события | один сигнал, cooldown, dismiss выключает повторы |
| Диалог | выходит из края и раскрывает speech/разговор по запросу | close возвращает в прежнее состояние, focus возвращается trigger |
| Свой промах | характерная сдержанная реакция/признание ошибки | никаких выдуманных «отменил»/«проверил», пока инструмент не подтвердил |
| Слушает/думает | видимая занятость только пока реальное действие выполняется | отмена/ошибка/ответ завершают состояние, нельзя бесконечно «думает» |
| Отдых/возврат | мягко прячется за край/в компактный знак | остаётся доступный ручной вызов, respects quiet/reduced motion |

Условия поведения различаются по персонажу, но не меняют полномочия. Перед реализацией решить edge/safe-area/keyboard/scroll/anchoring для каждого экрана, приоритет нескольких событий (один активный), права инициативы, cooldown/частоту, drag за край/защиту от accidental click, contrast и screen reader equivalents. Mobile не рассчитывает на hover. Не показывать личный дневник/контекст другого модуля в глобальной подсказке. Эти сценарии **не реализованы как product dispatcher** в текущем demo; не считать дизайн одобрением paid calls/пишущих инструментов.
