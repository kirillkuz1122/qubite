Для мелкого текста/контролов используются отдельные semantic tokens и контрастные оттенки: например, функциональная терракота Nacre `#b95433`, Folio `#a74e2e`. ## Что именно доступно для просмотра

У каждого направления отдельная landing-композиция в `src/pages/`; четыре экрана × пять концепций = **20 сцен**, а не пять перекрашенных скриншотов.

1. **Лендинг**: типографика, навигация, живая скульптура, CTA и capability-карточки; кнопки ведут в настоящие экраны прототипа.
2. **Интерфейс**: Today, Docs, Search, Writer, VPN, Modules, Settings; отдельная Console из Settings. Общие синтетические сценарии позволяют сравнивать разные пространственные композиции на одинаковом содержимом.
3. **Вход**: login/register/reset, focus/error/loading/success/OAuth-unavailable, show-password/private. Никакой реальной регистрации или передачи данных.
4. **Материал**: восемь явных состояний, регулируемая энергия, палитра, font specimen и описание характера движения.

Верхняя полоса переключает направление, экран, размер и тему; остаётся доступной при прокрутке. Прямой URL `/#/<direction>/<view>` работает на статическом хостинге. Материал реагирует и на pointer, и на семантические действия; телефон не зависит от hover.

## Язык движения

Общий event contract: `idle`, `focus`, `private`, `success`, `error`, `search`, `connect`, `capture`. У каждого материала собственные селекторы/геометрия/траектории, общая только семантика события.

| Событие | Nacre | Ferro | Folio | Prism | Milo |
|---|---|---|---|---|---|
| Pointer/касание | Свет и наклон дисков | Притяжение массы | Параллакс бумажных слоёв | Наклон/сдвиг нитей | Глаза, поворот мягких фигур |
| Focus | Устойчивое сближение | Сбор вокруг ядра | Раскрытие листа | Стягивание узла | Любопытный наклон |
| Capture | Сжатие/возврат | Импульс массы | Перелистывание | Волна | Растяжение/наклон |
| Success | Керамическая сборка | Слияние | Складка/закладка | Световой импульс | Последовательный прыжок и улыбки |
| Error | Неустойчивый наклон | Отталкивание | Красный акцент/штрих | Напряжение | Опущенные формы/изменение рта |
| Search | Новая ориентация | Scan | Поиск между листами | Веер | Взгляд в сторону поиска |
| Connect | Замкнутая форма | Связь спутников | Сбор листов | Замкнутый контур | Персонажи сближаются |
| Private | Материал закрывается | Масса уплотняется | Лист закрывает детали | Ткань стягивается | Персонажи отворачиваются и закрывают глаза |

Pointer записывает CSS variables через один requestAnimationFrame, не вызывает React render на каждый mousemove. При уходе pointer ожидающий frame отменяется. SVG filter Ferro создаёт соединение форм, а не blur текста. SVG IDs уникальны через useId, поэтому большие/маленькие материалы не конфликтуют. События действий двигают декор, а данные/поля/цели нажатия сохраняют стабильное положение; у контролов отдельная краткая тактильная реакция.

Режим **«Спокойный»** отключает циклические анимации, переходы и pointer движение. Системное `prefers-reduced-motion` включает его автоматически и имеет приоритет. Декор `aria-hidden`; результат действия также выражается текстом/status/error, а не только цветом/движением. Forced colors имеет отдельные правила. Это реализация Web-прототипа, не проверка экранного диктора или физики пера.

## Responsive и проверка

Container queries привязаны к ширине самой концепции: встроенный phone/tablet preview действительно переключает layout, а не уменьшает скриншот. Phone — одна колонка, перестроенная навигация и полноценные touch controls; landscape сохраняет прокрутку и не обрезает длинные формы. Desktop — собственный ритм каждой концепции. Нет device orientation permissions или датчиков.

Автоматически проверены ширины **320/360/768/1440** и landscape **844×390**, все четыре экрана каждого направления. Есть клавиатурный skip link, labelled inputs/buttons, screen-reader status, required/error text. Axe WCAG2A/AA/2.1AA проходит для четырёх экранов × двух тем × пяти направлений. Автоматический pass не гарантирует полную доступность: физический телефон, Safari, TalkBack/VoiceOver, zoom/Ink и длительное чтение остаются acceptance владельца.

## Заимствование и границы

[ArtCraft](https://getartcraft.com) и [Liquid Glass](https://github.com/Glass-HQ/liquid-glass) просмотрены как указанные владельцем референсы. Из них не копировались компоненты/дизайн/SDK. Идея выразительной реакции формы на пароль взята из приложенных пользовательских кадров; собственные персонажи/геометрия/анимации написаны с нуля. CSS/SVG подход выбран для непрозрачных поверхностей и независимости от WebGPU. Variable fonts self-hosted, OFL сохранены в source.

Никаких calls к core/legacy/AI/Telegram/VPN, storage/cookies/analytics, реальных профилей/грантов. Синтетическая роль — только переключатель макета. Выбор стиля не согласовывает автоматически auth/cutover/editor engine/native client architecture. Следующий шаг — приёмка пяти механик Milo, конкретные правки и фиксация production tokens/motion budget; после этого отдельные approved задачи нового UI по harness.
