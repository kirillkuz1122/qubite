# Задачи

Задачи живут в **GitHub Issues**: одна карточка на задачу, заголовок «ID — название», статус — метка (D-624).
Старый файл с карточками — [archive/TASKS-2026-10-29.md](archive/TASKS-2026-10-29.md): только grep по номеру, целиком не читать.

- **Метки статуса:** `backlog` · `ready` · `in_progress` · `review` (ждёт приёмки владельца) · `blocked` · `idea` · `later`. Готовая задача — issue закрыт.
- **Метка раздела:** `area:eng`, `area:ds`, `area:ops` … (по префиксу номера).
- **`codex`** — задание для Codex на Pi (D-623).
- **Новая задача** — новый issue: номер следующий по префиксу, цель, что входит, «готово, когда…», ссылки на решения.
- **Найти карточку:** поиск issues по номеру (`HAR-001`). Порядок — [STATUS](../project/STATUS.md), «Очередь».
- Эпики после MVP — [ROADMAP](ROADMAP.md).
