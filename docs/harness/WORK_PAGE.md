# Раздел «Агенты» в Owner Console (HAR-002, D-650…D-656)

Владелец видит работу агентов на qubiteapp.online → Owner Console → «Агенты». Данные — открытые GitHub Issues, сервер читает их своим токеном и обновляет раз в 3 минуты.

| Метка | Где видно |
|---|---|
| `вопрос` | «Ждёт тебя» — кнопки вариантов и поле «свой ответ» |
| `review` | «Готово — проверь» |
| `in_progress` | «Идёт» |
| `ready` | «Очередь», по номеру issue |
| `лимит` | «Лимит агентов» — последний комментарий |

## Задать вопрос владельцу
Issue с меткой `вопрос` (или метка на issue задачи). Тело:

```
Где хранить ночные бэкапы? На карте Pi 9 ГБ, бэкап за неделю — 4 ГБ.

- На внешний USB-диск (рекомендую)
- В облако, шифрованно
- Только последние 3 дня на карте
```

Текст до списка — вопрос; пункты — кнопки, первый — рекомендация. Ответ приходит комментарием «Ответ владельца: …», метка `вопрос` снимается. Агент читает ответ из комментариев issue (`issue_read get_comments`) — копировать ничего не нужно. Варианты — до 8, каждый до 200 знаков.

## Лимит
Управляющая сессия держит один открытый issue «Лимит агентов» с меткой `лимит` и пишет туда комментарий: `Лимит: окно 35%, неделя 62%` (можно дописать что угодно после). Раздел берёт последний комментарий.

## Ссылки
PR попадает в карточку, если в его заголовке или тексте есть `#N` («Closes #78», «Часть #78»). Скриншоты и PR из текста issue — тоже.
